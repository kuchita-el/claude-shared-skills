# ADR-202608070711-01-adr-parked-section-abolition: 「保留した決定」セクションを廃止し、射程の限定を働く箇所の散文へ戻す

## Context

ADR-202607201441-01-adr-parked-decision-section は、ADR スキーマに第一級セクション `## 保留した決定`（意図的に決めなかった facet の起票時点スナップショット）を導入し、その充足・棄却の規約を定めた。本 ADR はその2決定を反転する。原 ADR の第3の決定（非 Supersede 関係の参照妥当性 lint の要件定義）は生存するため、原 ADR は分割（1→N の部分上書き）により本 ADR と ADR-202608070709-01-adr-related-reference-validity-lint の2本へ退役した。

反転の根拠は運用実績の実測である。

- **使用実績が薄い**: 節を持つのは `validity: 有効` な ADR 48本中4本のみであった（分母は有効 ADR index のエントリ数）。中身は4本とも「この論点は本 ADR では決めない（想定継承先: #Issue番号）」という同型であり、Issue へ送った射程外の論点にあたる
- **機械検査の発火対象がゼロ**: 4本ともパーク欄に ADR スラグを1件も含まない。同節を対象とする dangling 検査は、検査しうる対象が corpus に1件も存在しないまま、`Related:` に対して「退役検査は非適用」という非対称を1つ増やしているだけの状態であった
- **主たる存在理由が消滅した**: 原 ADR の Context によれば、同節は旧 Amend 関係の移行で「充足か上書きか」を判別する証跡として作られた。その移行は完了しており（corpus の Amend 相互参照行は0件）、going-forward で同種の関係を生む構えになっている実例は無い。なお原 ADR はもう1つの動機として、散在していた未決表現を第一級セクションへ集約し機械的に位置特定できるようにすることを挙げていた。この動機は消滅していないが、機械的な位置特定を必要とする用途が判別の証跡以外に現れなかったため、本 ADR はこれを廃止を妨げる理由と見ない（失う利益は Consequences に計上する）
- **節名が実態と食い違う**: 原 ADR は同節を「意図的に決めなかった面の記録」と定義しているのに、節名は「保留した決定」であり、front-matter の状態語彙でも `## Decision` でもない第三の意味で「決定」を用いている
- **ADR 化要否の判定に寄与しない**: ADR 化の必要条件と格下げの条件はいずれも「意図的に決めなかった面は却下代替ではない」と明示的に除外しており、必要条件にも点数にも効かない

**却下した代替**

- **節を残したまま、充足を上書きと取り違えない識別分岐を編集判定フローへ足す**。却下理由: 証跡そのものが機能していない（発火対象ゼロ・使用4本）状態を温存したまま判定フローの分岐だけを増やす。識別の対象が実質的に存在しない分岐は、判定のたびに空振りの確認を強いる
- **節名だけを実態へ改める**（例:「意図的に決めなかった面」）。却下理由: 節名と実態の食い違いは解消するが、第一級セクションを保つコスト——機械検査の非対称、雛形の分岐、射程の限定を書く経路が本文の散文と専用節へ二重化すること——は残る
- **節は残し、機械検査だけを撤去する**。却下理由: 検査の無い第一級セクションは書式の担保を失い、`Related:` との非対称だけが残る。書式が担保されない節に、機械的な位置特定という当初の価値は無い

**ADR 化要否の判定**（起票の前段）: 必要条件（却下代替が在ること）は上記3件で成立する。粒度判定基準は4項目中3点である。項目1 は、反転すれば雛形・機械検査の実装・規約文書・テスト資産・既存 ADR 本文の書き換えが要り、加えて ADR スキーマの変更にあたるため該当する。項目2 は、規約スキル・検査スクリプト・ADR 成果物種別・テスト資産へ波及するため該当する。項目4 は、廃止後に同節を書いても検査が発火せず強制が働かないため該当する。項目3 は、規範の一部を雛形が体現する一方で決定2 の規定は散文にしか無く、該当するか迷うため同点処理により0点とした。境界の3点に達するため ADR 化する。行き先は既存 ADR の結論を反転する側であるから新規 ADR となる。

**束ねについて**: 本 ADR は2つの決定を持つが、両者はパーク欄の復活によって一体で反転する。節が戻れば射程の限定の書き場所も専用節へ戻るため、独立に反転しうる core を1本へ束ねない制約に反しない。

**同梱しなかった規範**: 節の廃止により、後継が先行の決めていない facet を決めた場合の分類から、パーク欄という証跡が失われる。その判別（先行の `## Decision` に無い facet を後継が決めることは反転に当たらない）は本 ADR の決定に含めない。同判別はパーク欄が復活しても偽にならず、逆に本 ADR の2決定を保ったまま単独で反転しうるため、束ねると独立に反転しうる core を1本へ束ねることになる。単独で ADR 化するかも判定したが、粒度判定基準は境界の3点に届かない。項目1 は、反転で書き換えが要るのが編集判定の規約1本にとどまり本数条件が0点である。非本数条件は4種を個別に見て、ファイル群の構造変更・スキーマの変更・蓄積済みデータの移行はいずれも非該当、「既に配布された成果物の利用者側への影響」は導入先の判定運用が変わる点で該当しうるが、規約1本の書き換えで取り消せるため該当するか迷い、同点処理により0点とした。項目2 は、規範の適用先が編集手続きに閉じるか ADR 成果物まで及ぶかを決めきれず同じく0点とした。項目3 は、採用理由を当該規約へ併記して自己完結させたため0点である。該当するのは機械強制の不在（項目4）のみで合計1点である。迷った2項目を仮に該当側へ倒せば3点へ達するが、項目単位の同点処理（迷う場合は0点）と「判断に迷ったら ADR 化しない」はいずれも境界未達側を指すため、規約の手続きに従い ADR 化しないと判定する。したがって行き先は共有規約文書であり、`manage-adr` スキルの編集判定の規約が採用理由・却下代替とともに保持する。

## Decision

### 1. `## 保留した決定` セクションを廃止する

ADR スキーマから第一級セクション `## 保留した決定` を削除する。雛形は同節を持たず、機械検査も同節を対象としない。

- 既存の同節を持つ `validity: 有効` な ADR は、決定2 の規定に沿って射程の限定を本文へ変換し、節を畳む。廃止は going-forward に限らず遡及する
- 退役済み ADR の同節は凍結原則により編集しない。歴史的成果物として残る

### 2. 射程の限定は、それが効く箇所の散文へ書く

「本 ADR が意図的に決めなかったこと」を書く必要がある場合、専用セクションを設けず、その限定が効く箇所へ散文で書く。

- 特定の決定に掛かる限定は、当該決定の本文へ注記として置く
- ADR 全体に掛かる限定は `## Context` へ置く
- 追跡が要る論点は Issue 側で追う。ADR 本文に置くポインタは非拘束であり、追随更新の義務を負わない

## Consequences

- **得られる利益**: 機械検査の非対称が1つ減る。雛形から宙吊りのポインタ（実在しない「『保留した決定』節の運用規約」への参照）が消える。射程の限定を書く経路が本文の散文へ一本化され、書き手が専用節と本文のどちらへ書くかを迷わなくなる
- **受容したトレードオフ**: 意図的な非決定は機械的に位置特定できなくなる。位置特定を必要としていた唯一の用途（充足か上書きかの判別証跡）は編集判定の規約が引き取るが、散在した散文を機械的に集める手段は残らない
- **受容したトレードオフ**: 引き取った側の判定は、先行の `## Decision` の記述がどこまで及ぶと読むかに依存する。明示のパーク記録が無いぶん、facet が先行の決定の射程内にあったか否かはテキストの解釈に委ねられる。ただし判定材料は先行の `## Decision` 本文であり、走査面は閉じている
- **決定2 との結合**: 決定2 は特定の決定に掛かる射程の限定を `## Decision` の中へ置かせるため、引き取った側の判定を「facet が `## Decision` に現れるか」という字面の存否で行うと、射程を明示した ADR ほど誤って退役側へ倒れる。判定は結論の有無で行う必要があり、その旨は編集判定の規約が保持する。中立の置き場所であったパーク欄を廃した代償として、2つの規定が判定材料を共有する結合が生じている
