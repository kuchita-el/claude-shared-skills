# ADR-20260726-04: モデル制約由来の設計判断インデックスを廃止する

## Context

本 ADR は ADR-20260711-3-adr-two-axis-status-validity-model（以下、原 ADR）の分割により生じた後継のひとつである。決定内容は原 ADR で承認済みのものを逐語 restate したものであり、内容の再決定ではない。

### 分割の経緯

原 ADR は8つの決定を束ねる多決定 ADR だった。そのうち決定8「採番方式・配置」の採番方式項が ID 形式の単一化（#550）で core 反転したため、原 ADR 決定3 が定める多決定 ADR の部分 core 反転手続き（ADR分割）に従い、生存決定を独立に反転しうるクラスタごとの後継へ逐語 restate し、原 ADR を `上書き済み` へ退役させた。

後継は6本である。本 ADR は原 ADR の**決定7（モデル制約由来の設計判断インデックスの廃止）**を単独で担う。単独としたのは、この決定が他のどの決定へも波及しないためである。索引の復活・再廃止は単独で判断できる。残る決定は ADR-20260726-01（決定1・2・5）、ADR-20260726-02（決定3・4）、ADR-20260726-03（決定6）、ADR-20260726-05（決定8 の配置項）が担い、反転した採番方式は ADR-20260726-06 が新決定として置き換える。

### 原 ADR からの改変箇所と理由（開示）

1. **見出しの先頭番号の振り直し**: 原 ADR の `### 7.` を本 ADR では `### 1.` とした。番号は原 ADR 内での決定の並び順を示すものであり、後継では自身の決定集合における位置へ振り直す。見出しタイトルと決定本文は変更していない。
2. **`## Consequences` の取捨**: 本 ADR が担う決定7 に対応する記述のみを原 ADR から保持した（将来の留保事項1項）。この項目は複数の決定にまたがる1文であり、文を切らず全文のまま保持したため、同じ文が他の後継にも現れる。配分の全体像は分割を実施した #570 が持つ。

### 帰結記述に残る原 ADR 内の参照（読み替え）

逐語のまま保持した「将来の留保事項」の項は、原 ADR の決定番号と節を指したままである。同項がいう「決定5 本文」は ADR-20260726-01 の決定3（drift-lint）、「2026-07-21 変更履歴」は原 ADR の `## 変更履歴` を指す（本 ADR はいずれの節も持たない）。

## Decision

### 1. モデル制約由来の設計判断インデックス（15件）を廃止する

`docs/adr/README.md` 内蔵の「モデル制約由来の設計判断インデックス」は、設計要素別の人手キュレーション意味索引であり、モデル更新時の再評価トリガーとして設計されていた。その再評価フローは実運用で回っておらず、今回の再設計の主眼（手動 drift 源を排する）と衝突する手動 drift 源であるため廃止する。意味逆引きは各 ADR 本文で代替し、ギャップ地図は必要なら別 Issue で扱う。

## Consequences

**将来の留保事項（本 ADR のスコープ外＝ downstream）**:

- 機構の実装（`scripts/lint-adr.sh` と PreToolUse フック合流、`docs/adr/index.md` 生成、`docs/adr/README.md` 廃止手順・`template.md` の改訂、ライフサイクル操作スキル）は実装 Issue に委ねる。この機構は実装済み。drift-lint はその後 ADR 運用機構のプラグイン抽出（#492/#493）で独立プラグイン `adr` 同梱の `plugins/adr/scripts/lint-adr.sh`＋同プラグインの PreToolUse ゲートへ移った（現配置は決定5 本文と 2026-07-21 変更履歴を参照。ここでの `scripts/lint-adr.sh` は起票当時に想定した合流先を指す）。
