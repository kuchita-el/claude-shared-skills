# ADR-202608070709-01-adr-related-reference-validity-lint: 非 Supersede 関係の参照妥当性 lint を要件として定める

## Context

本 ADR は ADR-202607201441-01-adr-parked-decision-section の分割（1→N の部分上書き）によって生じた後継である。原 ADR は3つの決定を束ねていた——「保留した決定」セクションの新設、その充足・棄却の規約、非 Supersede 関係の参照妥当性 lint の要件定義である。このうち前2件はパーク欄の廃止によって反転し、参照妥当性 lint の要件だけが生存する。原 ADR 全体を `上書き済み` にすると生存する決定まで退役するため、分割により本 ADR へ救出した。

原 ADR が当該要件を必要とした事情は次のとおりである。起票時点の機械検査が強制するのは `Supersedes:` の双方向性のみであり、`Related:` は検査対象外で dangling 参照を機械検出できなかった。

**分割に伴う改変の開示**

- **トップレベル番号の振り直し**: 原 ADR で当該決定は「3」であった。本 ADR で単独可読とするため「1」へ振り直した。決定本文は逐語で転記しており書き換えていない
- **`## Consequences` の調整**: 生存決定に対応する記述のみを保持し、退役する2決定に由来して無効となる記述を除いた。除いたのは「得られる利益」のうち充足／上書き分類の証跡・退役 ADR のパーク欄・未決表現の第一級セクションへの集約に関する3文と、「受容したトレードオフ」第3文の既存 ADR へのバックフィルを行わない旨の1文、および「記録先を新規 ADR とした理由」の項全体（原 ADR を新規 ADR として起こす判断の記録であり、分割後継には適用先が無い）である
- **一方向 `Related:` の実例記述の指し先**: 原 ADR は当該記述を「本 ADR 自身が起票時点で…」と自己言及の形で持っていた。本 ADR へそのまま移すと本 ADR 自身についての主張になり偽になるため、主語を原 ADR へ改めた。述べている史実は不変である

## Decision

### 1. 非 Supersede 関係の参照妥当性 lint（要件定義。実装は #474）

`lint-adr.sh` に、非 Supersede 関係の**参照妥当性検査**を追加する要件を定義する。実装は #474 が担う。

- **検査内容**: front-matter を持つ ADR の `## 関連ADR` 内の各 `Related: <slug>` について、`<slug>.md` が ADR_DIR に実在すること（dangling／typo 検出）。参照は full slug 完全一致で解決する。
- **不検査**: `Related:` の双方向性、Issue 番号参照（検査はオフライン実行を前提とし `gh` 等の外部照会を用いないため、`#<番号>` の実在は検査しない）。
- **`Related:` 双方向を強制しない**（＝一方向 `Related:` は合法）。双方向強制は、後継が `Related` を書くたび元 ADR へ追記＝さかのぼり編集を要し、退役 ADR では不可能で、凍結原則に反する。充足と上書きの分類は、後継側の一方向 `Related:` と先行 ADR の `## Decision` の記述で足り、双方向は分類に不要である。双方向は慣用（推奨）に留める。
- **#474 への申し送り**: 検査を有効化する前に、現行 corpus に dangling な `Related:` 参照が無いことを確認する（あれば lint が red 化する）。新レイヤとして足すかレイヤ3を拡張するかは #474 の実装裁量とする。

## Consequences

- **得られる利益**: dangling 参照が機械検出可能になる（#474 実装後）。
- **受容したトレードオフ**: `Related:` 双方向を強制しないため、片側だけの `Related:`（A は `Related: B` と書くが B が A に言及しない）という drift は lint で検出しない。これは凍結原則との両立を優先した結果で、双方向は慣用に留める。原 ADR が起票時点で `Related: ADR-202607112231-01-...` を一方向で持っていた（当時 711-3 は無編集）ことは、この一方向 `Related:` 合法の最初の実例である（711-3 はその後 #570 の分割で退役し、当該参照は後継 ADR-202607261459-01・ADR-202607261501-01 の2行へ付け替えられたが、一方向である点は変わらない）。
