# ADR-202608301012-01: 過去の記録を `docs/` へ保持せず、恒久的価値のある情報を正本へ移してから削除する

## Context

`docs/` 配下には、作成当時の状態を記録したまま現況へ追随しない文書（当時の設計 spec・観測記録・実験ログ・監査記録）が蓄積していた。これらは現行の規約文書と同じ階層に並び、読み手からもツールからも「現況を述べた文書」と区別がつかない。

区別のために恒久的なコストが発生していた。ある過去 spec 1本を残すために、冒頭の日付付き注記2本、走査テストの除外集合エントリ1件、受入条件の除外集合エントリ1件が必要になった。さらに同 spec が削除済みファイル名を保持していたため、統合先への参照が生きていることを確かめる needle が包含関係で無力化し、参照が全滅しても検査が緑を返す状態になっていた。原因は「消したはずの名前を持つ文書が走査面に残っていること」そのものにある。

本決定の時点で、ドキュメントをストック情報とフロー情報へ区別する軸は既にあったが、フロー情報の成果物を `docs/` へ恒久配置してよいかは定まっていなかった。区別の軸はあっても配置の規律が無いため、フローの成果物が `docs/` へ残り続け、そのたびに但し書きと除外集合で区別を補う運用が積み上がっていた。

本 ADR の射程は既存の過去記録の廃止規律であり、過去記録を生まないための起票時・作成時の予防は扱わない。

## Decision

**過去の記録をリポジトリへ保持しない。恒久的価値のある情報は、それを必要とするストック文書へ時点を明示した根拠として移したうえで、記録本体を削除する。**

`docs/` はストック情報の置き場とする。調査記録・作業記録・当時の設計 spec・実験ログは、フロー情報の定義（作業を駆動し、完了後は参照頻度が下がる）に当てはまるフロー情報の成果物であり、`docs/` へ恒久配置しない。

規範の実体——区分の定義、移設の線引き、恒久文書へ持ち込まない記述、参照掃きの除外——は `docs/references/document-permanence.md` へ置くこととし、本 ADR へは再掲しない。本 ADR が持つのは上記の決定と、次の射程、および却下代替である。パスを決定文へ明記するのは、本 ADR から規範の実体へ辿れない状態を作らないためである。

**射程の限定**

- **既存のストック／フロー軸へ接続し、新しい軸は立てない。** 既存の定義を改めることも本決定に含めない
- **移設の対象は、存続するストック文書が判断のために現に必要とする事実に限る。** 単一の出典であることを移設の十分条件にしない。線引きの実体は条文が持つ
- **恒久に追随義務を免れる形式を `docs/adr/` の ADR（専用ディレクトリ・識別子・front-matter の `status` / `validity`）に限り、本決定の区分を ADR 本体へ適用しない。** 区分対象外として据え置いたファイルが据え置きの間だけ免除を受けることは、これと別枠の一時の免除であり本項は妨げない。ADR の退役は格下げ判定が扱う別軸である

**却下した代替**

- **観測記録として別ディレクトリへ退避する**。退避は区別のコストを別の場所へ移すだけであり、「読み手もツールも但し書きを必要としない」という目的を達しない。走査面に残る以上、除外集合と needle の包含問題も解消しない
- **注記を足して据え置く**。区別のコストを恒久化する案であり、上記の恒久コストの実測がその帰結である。注記は読み手とツールの双方へ但し書きの読み取りを課し続ける
- **ストック／フローとは別の新しい軸を立てて説明する**。同じ対象に対して独自の定義を持つ第2の軸ができ、読み手はどちらの体系で判断するかを毎回選ばされる。採用案も「恒久文書」「過去記録」という呼称を置くが、これは既存軸の2値を配置判断の文脈で言い換えたものであり、定義を別に持たない。害が生じるのは語が増えることではなく、定義が二重化することである
- **`docs/principles.md` のストック／フローの定義自体を改める**。ADR-202607182303-01 の core 反転にあたり、規範の内容を変えたいわけではないのに ADR を1本動かすことになる

## Consequences

**受容したコスト**

- 削除した記録が保持していた当時の文脈（工程分割、実施順序、着手時の実測値、逐条照合の過程）は、移設対象から外れる分については git 履歴からのみ取り出せる状態になる
- 実行中の機構が入力として消費している資産と、未完了の後続作業が引き継ぎ文書として参照しているものは据え置く。据え置いたファイルは据え置きの間だけ追随義務と参照掃きの双方の対象から外れ、内部に残る参照は据え置きが解ける時点まで解消されない
- 恒久文書の内部に残る時点固定の節も処理の対象になるため、ファイル単位の判定より作業量が増える

**得られた利益**

- 走査面から過去記録が消えることで、参照掃きの受入条件へ恒久の除外集合を積む必要が `docs/adr/` を走査面に含める場合に限られる。据え置き中のファイルのパスも受入条件へ名指しされるが、据え置きが解ける時点で消える一時のものである。除外集合が走査面を無検査で削る形の検出網の無力化が起きにくくなる
- `docs/` 配下のどの文書も現況として読めるため、読み手もツールも「これは当時の記録である」という但し書きを必要としない

**役割分担の帰結**

条文の改訂は、本 ADR の決定とその射程を反転しない限り ADR の遷移を要しない。反転する改訂は上書き遷移を要する。規範として何が正しいかは条文が述べ、なぜそう決めたか・何を却下したかは本 ADR が保持する。

**再検討する条件**

据え置いた2類が恒常化し、除外の運用コストが過去記録を保持していた頃と同等まで戻った場合。
