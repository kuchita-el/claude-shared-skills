# ADR-202608061516-01: 配布境界の第3の判断軸に実行不能性テストを据える

## Context

配布物（プラグインとして配る資産）と配布元（本リポジトリに留める資産）の境界は、#623 で根拠を規約文書へ集約した時点では2つの軸で判断していた。配布先の環境で参照が解決できるか、および配布元固有のデータを含むか、である。#652 はこの2軸により、配布物内に在った配布元固有の管理表を配布元へ移した。

この2軸では、1つの文書の中で動作契約と根拠を分ける線を引けなかった。設計文書そのものを配布物へ置くかは #652 の移設では未決のまま残った。構造的な理由は、既存の2軸がいずれも**資産を配布物の外へ出す**向きにしか働かないことにある。手順が判定に要る定義を自ら持たず、その定義を抱える文書がたまたま同梱されているために参照は解決できている、という状態を2軸は誤配置として検出しない。当該文書が別の理由で配布元へ移った時点で、手順は初めて評価不能になる。

#657 で growth の設計文書を分割するにあたり、次の2点を実測した。

- **原理を動作の判定根拠として名指す全箇所で、同一行に内容を再掲していた。** したがって名指しを落としても動作の定義は手順の側に残る。表の「対応原理」列のような由来注記は動作の判定に効かないため、**本テストの射程外**である。射程を動作の判定へ限って初めて「その定義が要るか」で線が引ける。
- **定義を配布物の外へ委譲していたのは強キャリア（学びを載せる媒体のうち、テキスト規範より強い構造的なものを指す概念）だけだった。** 他の概念は配布物側の spec に実体定義を持っており、引用の内在化と誤引用の除去で足りた。移設を要する概念が1件に絞れたことで、本軸の適用が実行可能な規模に収まることを確認できた。

## Decision

### 1. 配布物と配布元の境界判断に、第3の軸として実行不能性テストを据える

**ある定義を配布物へ入れるかは、その定義を持たずに手順を読んだときに、手順のどの行かが評価不能になるかで判定する。** 評価不能になるなら、その定義は配布物の側になければならない。充足の手段は、配布物内から配布元にある定義を指すことではなく、定義そのものを配布物へ入れることである。

**射程は動作の判定に限る。** 落としても手順の判定が成立し続ける記述——概念の由来を示す注記や背景の説明——は、本軸では配布物へ引き込まれない。

本軸は、文書をどちらへ置くかの決着を待たずに、動作の判定に要る定義を配布物側へ引き込む。既存の2軸が資産を外へ出す向きにしか働かないのに対し、本軸は定義を中へ入れる向きに働く。

本軸は growth 限定ではなく、リポジトリ横断の判断軸として立てる。条文の形が固有語を含まず一般であり、固有なのは適用結果の側だけだからである。**その規定は、#657 の中で配布境界の規約文書の判断軸を述べる節へ置いた。**

**本 ADR は適用手順としての条文を併置しない。** 判断基準の実体と ADR の双方が同じ規範を現在形で保持する構造は、片方が黙って陳腐化する drift 源である（ADR-202608011651-01 が同型の構造を診断した）。本 ADR が保持するのは、第3の軸として実行不能性テストを据えるという構造、その射程を動作の判定へ限ること、および採らなかった代替とその却下理由である。

## Consequences

**得られた利益**:

- 文書単位ではなく定義単位で線を引けるようになる。ある文書を配布元へ移す判断と、その文書が抱えていた定義を配布物へ残す判断を、互いの決着を待たずに独立して下せる。
- 同梱されている文書に寄りかかって参照が解決している状態が、誤配置として現れる。既存の2軸ではこの状態は通過し、文書の配置が動いて初めて破綻が露見していた。

**却下した代替案**:

| 却下した案 | 却下理由 |
|---|---|
| 被参照テスト（配布物内のどこから参照されているかで、配布物へ残すか配布元へ移すかを振り分ける） | 被参照の有無は動作定義の所在と一致しない。名指しが由来注記にすぎず内容が同一行に再掲されている箇所では、参照が在っても定義は要らない。逆に手順の文言が定義を暗黙に前提している箇所では、参照が無くても定義は要る。加えて参照は指す側の記述選択で決まる片方向の関係であり、同格の資産どうしでも、たまたま指されたか否かだけで配置が割れる非対称が起きうる。配置の根拠が資産自身の性質ではなく、他の資産がどう書かれたかに従属することになる |

**受容したコスト**:

- **原理の名指しを配布物から落とすと、由来の導線が消える。** 名指しは動作の判定に効かないが、その動作契約がどの原理に由来するかを読者へ伝えてはいた。落とした後は、経緯を知らない読者が名指しの不在を参照の欠落と誤認しうる。導線を配布物の側へ残すには配布物から配布元を指す参照が要り、それは第1軸と両立しないため、この犠牲は受容する。
- 判定に本文の読解を伴い、機械検査できない。評価不能になるかどうかは、手順を実際にその定義抜きで読まなければ決まらない。
