# ADR-202608011651-01: ADR の固有価値を却下代替に定めて起票の必要条件とし、粒度判定基準の項目と境界は運用文書へ委ねる

## Context

ADR-202608011350-01 決定1 は、ADR の固有価値を却下代替に置き、それを粒度判定基準へ前置する必要条件として定めた。同決定はあわせて、粒度判定基準の4項目の名称とスコア境界を決定本文へ逐語で書き、「4項目の名称・値域・スコア境界・『判断に迷ったら ADR 化しない』の向きは変更していない」と明言していた。

この逐語保持は2つの問題を持つ。

第一に、単一出典の宣言と衝突する。判断基準の実体を担う運用文書は、当時その冒頭で「本ファイルがこれらの判断基準の実体であり、判定項目・スコア境界をここ以外で独自に再定義しない」と宣言していた。権威が運用文書へ在るにもかかわらず定義を現在形で併置する構造は、記述が偽になりうる drift 源である。同型の構造は 2026-07-30 の適格性監査（#625）でも検出され、そのときは併置していた側を同期して閉じた。

第二に、改訂コストが ADR 側へ伝播する。項目の名称を1語変えるだけで決定本文の逐語記述が偽になり、決定の反転を要する。#641 で現にこれが起きた。粒度判定基準の判定手続き層は判定のたびに新しい曖昧性が現れて個別に塞ぐ改訂が続いており（ADR-202608011350-01 が Context で診断したとおり）、逐語保持を続ける限り運用文書側の改訂が ADR の反転を繰り返し呼ぶ。

本 ADR は ADR-202608011350-01 決定1 を置き換える後継である。必要条件そのものは同決定から変更せず、逐語保持だけをやめる。**本 ADR 自身は却下代替を5件持つため必要条件を満たす**（後掲「却下した代替案」）。既存 ADR への core 変更に伴って後継を起こす操作は当時の `edit-decision.md` の core 分岐が定めていたものであり、そのために必要条件の適用範囲へ免除を足すことはしない。

## Decision

### 1. ADR 化要否は、却下代替の必要条件を満たした場合に限り粒度判定基準で判定する

**ADR の固有価値は、採らなかった選択肢とその却下理由（なぜ他ではないか）を保持することに在る。** 何が正しいかを述べる規範本文は、共有規約文書・spec・実装・スキーマ等、現在の正しさを保持し続ける資産の責務である。

この定義を ADR 化要否の判定へ、粒度判定基準に**前置する必要条件**として置く。

**必要条件**: 当該決定について、採らなかった選択肢とその却下理由が在ること。却下した選択肢の名指しと却下理由が対として特定できることを要し、代替案の名指しだけ、あるいはトレードオフや受け入れたコストの記述だけでは成立しない。意図的に決めなかった面（保留した決定）は却下代替に当たらない。**成立するか迷う場合は不成立とする。**

**不成立の場合は点数を数えず ADR 化しない。** 却下代替を持たない決定は資産側へ書けば足りる。

**粒度判定基準**: 必要条件は十分条件ではない。成立した場合に限り粒度判定基準へ進み、チェックリストの合計点で要否を判定する。

必要条件の同点処理は「書かない」側へ倒す。粒度判定基準の側がスコア境界と項目単位の同点処理に与えている向き（判断に迷ったら ADR 化しない）と一致させる。

**適用範囲**: 本必要条件は、**まだ記録されていない決定を新たに ADR として記録すべきか**の判定に掛かる。多決定 ADR の分割による後継への re-home は、既に記録された決定をファイル間で再配置する構造操作であり、新たな記録の判定ではないため本条件の対象外である。分割時に後継が満たすべき条件は分割手続きの側の規範であり、ADR-202607261501-01 決定1 が定める。したがって却下代替を持たない決定が分割後継として corpus に現れうる。その後継を退役させるかは、起票の判定ではなく既存 ADR の格下げ判定が扱う。

### 2. 粒度判定基準の判定項目とスコア境界は、本 ADR の決定内容に含めない

**粒度判定基準が何項目で構成され、各項目が何という名称を持ち、境界の点数が何点であるかは、本 ADR が保持しない。** これらの実体は ADR 化要否の判断基準を担う運用文書が保持するものとし、本 ADR はその存在と、必要条件を前置するという構造だけを決定する。

本 ADR が保持するのは次の4つに限る。

- 固有価値の定義（却下代替）と、それを必要条件として前置する構造
- 必要条件が十分条件ではなく、成立時に限り粒度判定基準へ進むという順序
- 必要条件の同点処理の向き（書かない側へ倒す）と、それを粒度判定基準側の向きと一致させること
- 必要条件の適用範囲（まだ記録されていない決定を新たに記録すべきかの判定に掛かること、および多決定 ADR の分割による後継への re-home を対象外とすること）

項目の追加・削除・改名、および境界の点数の変更は、運用文書の改訂として行い、本 ADR の反転を要さない。ただし**必要条件を前置する構造そのものの変更、または上記4つの反転**は本 ADR の反転にあたる。適用範囲を保持対象へ含めるのは、それが判定項目や境界の内訳ではなく必要条件そのものが何に掛かるかを定めるものだからである。

本 ADR 起票時点（2026-08-01）で、この必要条件と粒度判定基準を実務手順として運用する実体は `adr` プラグインの `manage-adr` スキルの参照ファイルへ置かれていた。以後、実務手順の所在や表現が変わっても、上記4つの骨子は本 ADR が保持する。

## Consequences

**得られた利益**:

- ADR 化要否の判定が、規則を網羅的に述べきれない粒度の項目群だけに依らなくなる。却下代替の有無は当該 ADR 本文のみを走査面とする閉じた判定であり、判定者間で結論が収束しやすい
- ADR と資産の役割分担が判定基準の側から言えるようになる。規範本文しか持たない記録は資産の写しであり、index に置く固有の価値を持たない
- 判断基準の単一出典が実際に単一になる。運用文書が当時掲げていた宣言（判定項目・スコア境界をここ以外で独自に再定義しない）に対して、ADR 側が例外でなくなる
- 判定項目の字句改訂が ADR の反転を呼ばなくなる。運用文書側の改訂頻度と ADR の改訂頻度が切り離される

**却下した代替案**:

| 却下した案 | 却下理由 |
|---|---|
| 4項目の名称とスコア境界を決定本文へ逐語で保持し続ける（ADR-202608011350-01 の形） | 運用文書が当時「判定項目・スコア境界をここ以外で独自に再定義しない」と宣言していた以上、逐語の併置は権威が移譲済みの場所に定義を現在形で置く drift 源である。加えて、判定手続き層は適用のたびに新しい曖昧性が現れて塞ぐ改訂が続いており、逐語保持は項目名1語の改訂ごとに ADR の反転を呼ぶ。#641 でこの伝播が現に発生した |
| 逐語保持をやめる代わりに、運用文書の該当節を指す参照を決定本文へ置く | 参照は可変文書を現在の参照先として現在形で指すことになり、記録の参照原則（ADR-202608011355-01 決定1）に抵触する。所在は時点固定の過去形で1度述べるに留め、決定内容としては持たない |
| 起票基準と同じ抽象度で第2の判定基準を新設し、格下げ専用に使う | 粒度判定基準の改訂履歴が示すとおり、この抽象度の規則は適用のたびに新しい曖昧性が現れて個別に塞ぐ反復を招く。第2基準を立てれば同じ反復をもう1本量産する |
| 設計判断型（なぜそう構造化したかが資産に現れない）と機能要件型（正本が構成上、資産側にあるのが自然）で仕分ける軸を前置する | 43本を仕分けた実測で内訳がバッチ間で大きく偏り、境界が判定者によって動いた。加えて機能要件型であることが退役可否と対応しない。二層構造の下では規範内容が資産側に在ることは設計上の意図であって欠陥ではなく、機能要件型と判定された記録の多くは、当時の資産側が明示的に根拠を ADR へ委譲していた |
| 二層構造（規範内容は資産側、採用決定と却下代替は ADR 側）そのものを反転し、ADR に規範本文の保持を認める | 59本の実測で7割超が却下代替を本文に持ち、当時すでに二層構造は履行されていた。是正すべきは構造ではなく履行していない側である |

**受容したコスト**:

- 却下代替を持たない決定は、粒度判定基準の点数が境界へ届いても ADR 化しない。従前なら ADR 化していた決定の一部が資産側へ回る
- 必要条件の判定は本文の読解を伴い、機械検査できない。この点は粒度判定基準の各項目と同じである
- **本 ADR だけを読んでも、粒度判定基準が何項目で境界が何点かは分からない。** 判定を実行するには、当時の運用文書を併せて読む必要があった。ADR ファイルの自己完結性は、決定の骨子については保たれるが、判定手続きの実行可能性については保たれない。判断基準の単一出典と引き換えに受け入れた
- ADR 化自己評価として旧項目名を引用している既存 ADR は、当時の判定の記録として旧名称のまま残る。項目名の改訂は遡及しない
- **過去の ADR 化自己評価が「4項目チェックリスト」の出典として現在形で指せる ADR 側の宛先は、本決定により以後存在しない。** 既存の自己評価は当時現行だった ADR（上書き済みを含む）を指したまま据え置く。退役に伴って inbound の散文引用を後継へ付け替える扱い（ADR-202608011350-01 の起票時に採った方針）は、本 ADR を宛先とする場合には適用しない。付け替えると「本 ADR 決定1 の4項目チェックリスト」という偽の記述を作るためである
