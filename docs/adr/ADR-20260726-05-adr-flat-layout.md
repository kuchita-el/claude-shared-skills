# ADR-20260726-05: ADR ファイルは docs/adr/ 配下にフラット構造で配置する

## Context

本 ADR は ADR-20260711-3-adr-two-axis-status-validity-model（以下、原 ADR）の分割により生じた後継のひとつである。決定内容は原 ADR で承認済みのものを逐語 restate したものであり、内容の再決定ではない。

### 分割の経緯

原 ADR は8つの決定を束ねる多決定 ADR だった。そのうち決定8「採番方式・配置（ADR-20260511 から不変で引き継ぐ）」は採番方式と配置の2項からなり、このうち**採番方式項のみ**が ID 形式の単一化（#550）で core 反転した。原 ADR 決定3 が定める多決定 ADR の部分 core 反転手続き（ADR分割）に従い、生存する配置項を本 ADR へ逐語 restate し、原 ADR を `上書き済み` へ退役させた。反転した採番方式は ADR-20260726-06 が新決定として置き換える。

後継は6本である。本 ADR は原 ADR の**決定8 のうち「配置」項**を単独で担う。採番方式と配置を別の後継へ分けたのは、両者が独立に反転しうるためである（採番方式の反転は配置の変更を要求せず、逆も同じ）。残る決定は ADR-20260726-01（決定1・2・5）、ADR-20260726-02（決定3・4）、ADR-20260726-03（決定6）、ADR-20260726-04（決定7）が担う。

### 原 ADR からの改変箇所と理由（開示）

1. **決定見出しの文言変更と先頭番号の振り直し**: 原 ADR の `### 8. 採番方式・配置（ADR-20260511 から不変で引き継ぐ）` を本 ADR では `### 1. 配置（ADR-20260511 から不変で引き継ぐ）` とした。本 ADR は決定8 のうち配置項のみを担い採番方式項を含まないため、見出しから採番方式を落として担当範囲と一致させた。番号は後継での位置へ振り直したものである。
2. **リード文の書き換え**: 原 ADR の「ADR-20260511 が定めた次の2項目は変更せず、本 ADR に引き継ぐ」を、本 ADR が引き継ぐ項目数に合わせ「次の項目」とした。決定本文（配置のバレット）は変更していない。
3. **`## Consequences` 節を置かない**: 原 ADR の `## Consequences` 8項目のうち、決定8 の配置項に由来する記述は1項目も存在しない。保持すべき記述が無い以上、埋めるために書けば記録の捏造にあたるため節ごと置かない（「該当なし」も書かない）。`## 保留した決定` 節について雛形が定める扱いと同型である。配分の全体像は分割を実施した #570 が持つ。

## Decision

### 1. 配置（ADR-20260511 から不変で引き継ぐ）

ADR-20260511 が定めた次の項目は変更せず、本 ADR に引き継ぐ（自己完結原則により restate）。

- **配置**: `docs/adr/` 配下にフラット構造。サブディレクトリは作らない。
