# ADR-202608011355-01: 記録は可変文書を現在の参照先として指さない

## Context

本 ADR は ADR-202607191825-01 の分割によって生じた後継である。同 ADR は「ADR 化判断の3基準」と「記録の参照原則」の4決定を束ねており、そのうち決定1（粒度判定基準）が ADR-202608011350-01 によって反転した。本 ADR は決定4（記録の参照原則）を引き継ぐ。原 ADR 自身が同決定を「決定1〜3の系ではなく、独立した横断規範」と位置づけていたため、3基準を引き継ぐ後継とは分けた。

原 ADR が本決定を立てた経緯は次のとおりである。#515 の反転作業（運用ルールの生きた正本を ADR 側から手順書側へ移す作業）の中で、凍結された記録であるはずの ADR が、後から書き換わりうる可変文書を「現在の参照先」として現在形で指している箇所が見つかった。指し先の内容が変われば、記録の意味は書き手の意図と無関係に変質する。さらに退役した ADR は凍結原則により決定内容を編集できないため、変質が起きても修復手段がない。

**原 ADR から改変した箇所**（分割手順が求める開示）:

- `## Decision` のトップレベル項目の先頭番号を `4` から `1` へ振り直した。後継での単独可読性のためであり、決定本文は逐語である
- 決定本文中の「本 ADR を起票した同一の変更セット」「本決定は決定1〜3の系ではなく」という記述は、原 ADR とその起票時（2026-07-19）の変更セットを指す。分割中に決定内容を変えない規約に従い、字句は原文のまま残した
- `## Consequences` は、決定1〜3 に由来する記述（3基準が corpus に入る利益、3基準と実務手順の乖離のトレードオフ、射程外是正による dangling の解消）を除き、決定4 に対応する記述を保持した

## Decision

### 1. 記録の参照原則

記録（ADR）は、可変文書を現在の参照先として指さない。指す必要がある場合は、時点を固定した過去形の記述にするか、参照先の実質を自己完結的に述べる。

**適用範囲**: 本原則は以後の ADR 起票および `有効` な ADR の編集に効くほか、既存 corpus にも及ぶ。本 ADR を起票した同一の変更セットは、`有効` な ADR 群および運用文書が `docs/adr/README.md` を現在の参照先として指していた箇所を是正の対象に含める。ただし退役した ADR の `## Decision` は、次の適用限界のとおり対象から除く。

**適用限界**: 既に退役（`validity: 上書き済み` / `廃止済み`）した ADR の `## Decision` に本原則違反が残る場合、凍結原則（ADR-202607261501-01 決定1）が優先し、是正しない。退役という事実自体がその記述に時点を供給するため、記録としての読み方は保たれる。この適用限界は本原則の構成要素であり、無条件の禁止を立てたうえで後から逃がす例外ではない。

本決定は決定1〜3の系ではなく、独立した横断規範として立てる。#515 が3基準の参照の張り替え先を運用ドキュメント外へ取れなかった理由そのものが本原則の違反構造にあり、また本原則は3基準と無関係に、以後の全 ADR 起票に対して効くためである。

## Consequences

**得られた利益**:

- 記録が指し先の変化で意味を変質させる経路が塞がれる。とくに退役後は修復手段が無いため、起票時点での自己完結性が事後の可搬性を決める。

**適用限界の実例（`ADR-202605312147-01` の未編集判断）**:

`ADR-202605312147-01`（`validity: 上書き済み`、後継 `ADR-202606020010-01-principles-rationale-hub`）は、その `## Decision`（同ファイル L23-32）の L29 で、操作層の SoT の一つとして `adr/README` を挙げている。字面のうえでは本原則の違反形（記録が可変文書を現在の参照先として指す）に見えるが、原 ADR を起票した Issue ではこれを未編集とする判断を採った。論拠は次の4点である。

- **(a)** L29 は `## Decision` の内部にあり、決定内容そのものである。ADR-202607112231-01 の決定3「編集機構（3段構え）と判定フロー」のうち凍結原則の射程を定める段落は、射程の一般規定を「この凍結原則の射程は決定内容の編集である」と置いたうえで、退役 ADR にも実施してよい類型を2つ具体的に認可している（front-matter（状態）にも `## Decision`（内容）にも触れず、状態の重複表示を消すだけの是正／固有情報を `## 関連ADR` へ移してから除去する移設）。この2類型は認可された具体例であって射程外の網羅列挙ではなく、可否を決めているのは一般規定のほう、すなわち決定内容に触れるか否かである。L29 はこの一般規定に照らして射程内であり、加えて同段落は「逆に、決定内容に触れる編集は退役 ADR に加えてはならない」と明示的に禁じている。
- **(b)** 同段落の末尾は、3段構えの判定フローを「`有効` な ADR への決定内容の編集を振り分けるもの」と限定している。したがって `validity: 上書き済み` の `ADR-202605312147-01` に対し、「非core だから直接編集してよい」という分類を適用することはできない。
- **(c)** 退役した ADR の決定本文は、その退役時点の記録として読まれる。L29 の記述は 2026-05-31 時点の状態の記録として正しく、その後に SoT が移動した事実は当該 ADR の退役という事実が既に伝えている。すなわち、`ADR-202607112231-01` の `## 変更履歴` の 2026-07-17 エントリ / 2026-07-19 エントリが可変文書への言及に対して採っている「時点明示」に相当する処理が、退役という事実によって構造的に既に効いている。
- **(d)** したがって本件は「記録が可変文書を現在の参照先として指している」未処理案件には当たらない。本原則の適用限界に照らし、凍結原則を優先して未編集とする判断である。

**適用有無の判定基準（`ADR-202607112231-01` の README 言及が処理と未処理に分かれた理由）**:

原 ADR を起票した変更セットは、`ADR-202607112231-01` が `docs/adr/README.md` に言及する箇所のうち `## 変更履歴` の 2026-07-17 エントリ / 2026-07-19 エントリを改訂し、`## Decision` の決定7「モデル制約由来の設計判断インデックス（15件）を廃止する」と `## Consequences`「将来の留保事項」の機構の実装に関する項は改訂しなかった。同一ファイル内で処理が分かれるため、両者を分けた基準を次のとおり記録する。

- **基準**: その記述の真偽が、参照先の現在の内容に依存して決まるかどうか。依存するなら時点固定または自己完結化を要し、依存しないなら記録として既に閉じている。
- **改訂した2箇所**: 2026-07-17 エントリは凍結原則の射程について「射程自体は README …で既に同内容が運用されており」と述べ、2026-07-19 エントリは「操作層の手順は README …が対応する」と述べていた。いずれも README が現にその規定を保持していることを現在形で主張しており、README を導線へ縮退させれば主張が偽になる。よって「当時の」を補い、時点を固定した過去の事実の記述へ改めた。
- **改訂しなかった2箇所**: 決定7 の本文は同決定が「廃止する」と述べた対象の同定（README 内蔵の索引を廃止する）であり、「将来の留保事項」の機構の実装に関する項は当時どこへ委譲したかの予定の記録である。いずれも README が現在何を保持しているかを主張していないため、指し先が空になっても記述は真のまま保たれる。
- **本原則との関係**: 本基準は本原則の禁止範囲を狭めるものではない。本原則は「可変文書を現在の参照先として指さない」を無条件に課しており、本基準はある記述がその「現在の参照先として指す」に当たるかを個別に見分ける手順にすぎない。判定に迷う場合は、参照先を空にした状態でその記述を読み直し、偽になるなら適用対象、真のままなら対象外として振り分ける。原 ADR の起票時点（2026-07-19）で、この振り分けを以後の編集へ適用する実務手順は `manage-adr` スキルの編集判定リファレンスにも置かれた。本節の記述は、当該変更セットで処理が分かれた理由の記録である。
