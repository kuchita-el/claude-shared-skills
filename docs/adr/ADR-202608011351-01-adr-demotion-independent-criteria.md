# ADR-202608011351-01: 格下げ判定を起票判定と独立の基準として立て、必要条件の連言で判定する

## Context

2026-07-30 の既存 ADR 適格性監査は、起票の前段として設計された粒度判定基準を既存 ADR へ遡及適用し、退役の可否を決めた。転用の妥当性は検討されていない。2026-07-31 の独立した再採点では、監査の非該当判定を5本中1本しか再現できなかった。

両判定は次の点で非対称であり、同じ項目・同じ境界・同じ安全側を共有できない。

- **コストの所在**: 起票では書くコストを今から払うかが問われる。格下げでは書くコストは既に埋没しており、検索性の負荷と参照価値が問われる
- **使える入力**: 起票では決定の性質のみを見る。格下げでは運用実績が観測できる
- **不可逆性の向き**: 起票しない判断は可逆であり、後から必要性が判明した時点で遡及して ADR 化できる。退役は index から外し、有効 ADR からの `Related:` 参照を規約上禁じ、本文を凍結原則の下へ置く。`廃止済み` から `有効` への復帰経路は、起票時点の規約に存在しない

## Decision

### 1. 格下げ判定は起票判定と独立の基準を持つ

既に記録された ADR を退役させる（`validity: 廃止済み` へ移して index から外す）かの判定は、起票判定とは別の基準で行う。**起票判定の粒度判定基準を既存 ADR へ遡及適用して退役を決めない。**

両基準が共有するのは、ADR の固有価値を却下代替に置く定義だけである（ADR-202608011651-01）。判定項目・境界・安全側は共有しない。

### 2. 判定形式は必要条件の連言とする

**全条件が成立した場合に限り退役させる。1つでも不成立なら存置する。** 条件ごとの点数を合計しない。

条件は次の2つとし、条件1 を主、条件2 を従とする。

- **条件1（却下代替の不在）**: 当該 ADR の本文に、自分の決定について採らなかった選択肢とその却下理由が書かれていないこと。走査面は当該 ADR の本文のみとし、他の ADR・規約文書・Issue・PR は見ない
- **条件2（規範本文の所在）**: 規範本文が ADR の外の資産に在る、または決定が現に効力を失っていること。規範を強制する実装・テスト・フック・CI が引き取っている場合を含む

条件1 のみで退役させない。却下代替を持たない ADR であっても、規範本文の正本がまだ当該 ADR にしか無いなら、退役させれば規範そのものが失われる。条件2 はその取りこぼしを塞ぐ。

### 3. 安全側は「迷ったら残す」とする

各条件は退役側へ倒すときのみ成立とし、**成立するか迷う条件は不成立とする**。1つでも不成立なら存置であるから、迷いは必ず存置へ落ちる。

起票時点の起票判定が置く「判断に迷ったら ADR 化しない」は、起票しない判断が可逆であることに支えられている。退役にはその支えがない。したがって向きを逆に取る。判定形式に連言を採ることで、この向きは全条件で一様になる。

## Consequences

**得られた利益**:

- 格下げ判定が起票判定の改訂から独立する。粒度判定基準の項目や境界が動いても、既存 ADR の退役可否は動かない
- 迷いの落ち先が全条件で一様になる。項目ごとに符号が異なるスコア式では、同点処理の向きが項目ごとに反転して誤りやすい

**却下した代替案**:

| 却下した案 | 却下理由 |
|---|---|
| 1つの基準を双方向へ拡張し、適用方向ごとの規定（安全側の向き・使える入力・境界）を基準内に分けて書く | 同じ項目が適用方向によって違う意味を持つことになる。項目の定義が方向に依存すると、どちらの読みで採点したかが判定記録から復元できない |
| 遡及的な格下げを行わず、index の ADR 過多は index の構造化で解く | 第1群5本の退役が既に実行済みであり、その判定の根拠が事後に必要になる。構造化は過多の見え方を変えるだけで、根拠を供給しない |
| スコア式（起票判定と同形の N 項目・境界値） | 項目間の相殺が起きる。不可逆側へ倒す判定において、ある項目の高さが別の項目の不成立を埋め合わせる形は適さない。加えて二値の少数項目によるスコアは同種の文書群に対して縮退する（監査では43本中31本が同一の並びへ張り付き、解像度を失った） |
| 段階式（必要条件のゲート＋通過分のスコアによる優先度付け） | 優先度が要る場面（大量の一括棚卸し）が現に生じておらず、第2段が空転する |
| 起票判定と同じ安全側（迷ったら退役側へ倒す）を採る | 起票しない判断は可逆だが退役は不可逆であり、復帰経路が起票時点の規約に存在しない。同じ向きを当てると迷いが記録喪失側へ落ちる |

**受容したコスト**:

- 連言と「迷ったら残す」の組み合わせは発火しにくい。退役候補は少数にとどまり、index の縮小は緩やかになる。取りこぼし（本来退役させてよい記録を残すこと）を、誤退役より軽いコストとして選んだ結果である
- 条件1・条件2 はいずれも本文および資産の読解を伴い、機械検査できない

本 ADR 起票時点（2026-08-01）で、この判定の実務手順は `adr` プラグインの `manage-adr` スキルの参照ファイルへ置かれた。以後、手順の所在や表現が変わっても、決定の骨子は本 ADR が保持する。
