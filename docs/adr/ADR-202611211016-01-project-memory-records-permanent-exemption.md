# ADR-202611211016-01: Project Memory の記録を、追随義務を恒久に免れる2つめの形式として `docs/memory/` に置く

## Context

ADR-202608301012-01 は、過去の記録をリポジトリへ保持しないと決めた。あわせて、恒久に追随義務を免れる形式を、`docs/adr/` の ADR に限った。

ADR-202611140016-01 が起こした `shared-memory` プラグインは、プロジェクトのリポジトリの中に記憶（Project Memory）を置く。既定の置き場は `docs/memory/` であり、最初の利用先は本リポジトリである。Project Memory の記録は、次の2点で、上の決定と整合しなかった。

- 起票の時点の記録の形式は、置き換えた記録を消さずに残すと定める。旧い記録は、置き換えた先を `superseded-by` で指す。遷移の記録（`evolution`）は、旧い記録を指す。検査器は、指された記録が無いことを違反にする。一方、上の決定は、過去の記録を残さない。注記を足して据え置く形も採らない。
- 記録は、観測した時点の事実を述べる。現在真であり続けるよう書き換えると、何をいつ観測したかが失われる。

Project Memory と同じ根の下には、タスクの間だけ持つ覚え書き（Task Memory）も置く。これはフロー情報である。

**既存の決定との関係**: 本 ADR の決定は、ADR-202608301012-01 の次の3点に触れる。

- 同 ADR の射程の限定は、恒久に追随義務を免れる形式を、`docs/adr/` の ADR に限ると定める。
- 同 ADR は、決定とその射程を反転する条文の改訂には、上書きの遷移を要すると定める。
- 同 ADR は、得られた利益を2つ挙げる。1つは、参照掃きの恒久の除外集合が `docs/adr/` に限られることである。もう1つは、`docs/` 配下のどの文書も現況として読めることである。本 ADR の決定の下では、どちらも `docs/memory/` の記録と索引について成り立たない。

ADR-202609110017-01 の決定6 は、転換期間中、ADR の遷移の操作（承認・上書き・廃止・分割）を本リポジトリで使わないと定めた。リポジトリの所有者は 2026-11-21 に、ADR-202608301012-01 の扱いを、この変更を進める側の判断に委ねた。あわせて、ADR を定期的に棚卸しし、不要になったものを整理することが要る、と述べた。棚卸しの仕組みは、起票の時点では無い。

**射程の限定**: 本 ADR は、本リポジトリの `docs/` 配下での Project Memory の扱いだけを決める。記録の形式、置き場の既定、Task Memory の残留を検出する仕方は決めない。採用の台帳（`docs/memory/adopted/`）は、免除の対象にしない。

## Decision

- `docs/memory/records/` の Project Memory の記録を、記録であることを構造的に宣言する形式として扱い、追随義務の恒久の免除を与える。この形式は、専用のディレクトリ、識別子（`MEM-…`）、front-matter の `superseded-by`・`moved-to`・`verification` を持つ。
- 過去の記録を残さないという区分を、記録の本体へ適用しない。記録の本文は、置き換え済みかどうかを問わず、時点の事実を述べたものとして扱う。古くなった記録は書き換えず、記憶の形式が定める置き換えで扱う。
- 索引（`docs/memory/index.md`）は、記録から生成する派生物であり、記録に従う。
- Task Memory は、この免除を受けない。作業中のブランチでだけ追跡し、既定のブランチへ入れない。既定のブランチの `docs/` は、ストック情報だけの置き場のままとする。
- 恒久に追随義務を免れる形式は、`docs/adr/` の ADR と、Project Memory の記録に限る。ADR-202608301012-01 が ADR に限った範囲を、本 ADR が広げる。
- ADR-202608301012-01 は編集しない。上書きも廃止もしない。有効のまま残す。転換期間中は、遷移の操作を使わないためである。
- 本 ADR の決定は、免除の反転ではない。免除を受ける形式を1つ足す拡張である。同 ADR が反転する改訂に求める上書きの遷移は、本 ADR の起票では行わない。
- それでも、同 ADR の「ADR に限り」の文と、得られた利益の2つの記述とは、字義で食い違いが残る。食い違いが残る間は、本 ADR と、恒久性の規約の現行の条文を優先して読む。
- この食い違いは、同 ADR の上書きの遷移として解消する。行う時点は、遷移の操作を使えるようになった時点か、ADR を棚卸しする時点である。
- 条文は、起票時点では `docs/references/document-permanence.md` の §1・§2・§3・§4・§6 が保持していた。

**却下した代替**:

- **記憶の根を `docs/` の外へ置く**: ADR-202608301012-01 の決定は「リポジトリへ保持しない」であり、`docs/` の外でも同じ問題が残る。同 ADR が却下した「別ディレクトリへの退避」と同じ形になる。プラグインが既定とする置き場を、最初の利用先が使わないことにもなる。
- **区分を記録へ適用し、置き換え済みの記録を消す**: 記録の形式と検査器に反する。本リポジトリだけが、別の形式を使うことになる。
- **実測した外部の事実だけを置く**: 自分で実測しないと得られない外部の事実は、独立した記録として残してよい。この既存の例外に収める案である。知識（`knowledge`）と判断基準（`belief`）を置けない。置き換えも扱えない。規範へ畳まない知識も残す、というこのプラグインの役割を失う。
- **本リポジトリには Project Memory を置かない**: 最初の利用先を本リポジトリとする方針を満たせない。プラグインが既定とする置き場を、配布元が自分で使って確かめられない。

## Consequences

- `docs/` 配下に、現況へ追随しない文書の置き場が1つ増える。参照掃きの受入条件が `docs/memory/` の記録と索引を走査面に含める場合は、`docs/adr/` と同じく、除外集合として名指しする。
- 読み手は、`docs/memory/records/` の文書を、現況ではなく時点の事実として読む。置き場と識別子と front-matter が、それを示す。
- 置き換え済みの記録が、リポジトリに残る。索引は、置き換え済みの記録を載せない。
- 記録が古くなったことに気づく仕組みは、本決定の外に在る。
- 免除を受ける形式が2つになる。3つめを足すときは、その都度、判断を記録する。
- ADR-202608301012-01 の整理（上書きの遷移）は、ADR を棚卸しする時点へ送る。それまで、同 ADR の射程の限定と、得られた利益の2つの記述は、本決定と字義で食い違ったまま残る。
