# ADR-202611100014-01: writing の一文長の検査器を素の ESM と同梱の解析器で配り、node で直接呼ぶ

## Context

writing プラグインの一文長の検査器は、シェルと awk で書かれていた。Markdown の構造を行頭の記号で推測しており、CommonMark と GFM の表の定義で構造を読めなかった。Issue #959 で、検査器を Node で書き直し、構造を解析器で読む形へ替えた。

書き直しに伴い、検査器の置き場、解析器の入手の仕方、スキルからの呼び方を決める必要が生じた。これらは、以後に node で動く検査器を配布物へ同梱するときの前例になる。

ADR-202611040012-01 は、living-spec の検査器を Release の添付物として配ると決めた。その際、生成物をプラグインへ同梱する案を却下している。writing の検査器はこの形に従わないため、差異と理由を記録する。

**射程の限定**: 本 ADR は writing の検査器の置き場・解析器の同梱・呼び方を決める。判定の規則と補則の中身は決めない。living-spec の検査器の配布の形は変えない。

## Decision

- 検査器は、自前のコードを素の ESM の単一ファイルとして writing プラグインに置く（`scripts/lint-ja.mjs`）。ビルドは持たない。静的な import は `node:` の組み込みだけにする。
- 解析器は markdown-it 15.0.3 とする。上流が配る単一ファイル `dist/browser/markdown-it.esm.min.mjs` を使う。中身を変えずに `scripts/vendor/markdown-it.mjs` として同梱する。`NOTICE.md` には、版・上流が示す dist.integrity・sha256 を記す。束ねられた8つの部品と、その許諾の全文も添える。
- 解析器は、検査器が動的な `import()` で try/catch の中から読み込む。読み込みに失敗したときは終了コード 2 で終わる。構成は `new MarkdownIt('commonmark').enable('table')` とする。
- スキルは `node "${CLAUDE_PLUGIN_ROOT}/scripts/lint-ja.mjs" …` で直接呼ぶ。`allowed-tools` は `Bash(node *scripts/lint-ja.mjs*)` とする。シェルの入口（`lint-ja.sh`）は削除する。
- front-matter は解析器の拡張を使わず、自前の照合で読む。
- 実行環境は Node 22 以上とする。22.23.2 と 24.16.0 で動作を確かめた。

**ADR-202611040012-01 との関係**: 同 ADR が却下したのは、自前の生成物をプラグインへ同梱する形である。本 ADR が同梱するのは、自前の生成物ではなく上流の配布物であり、中身を変えない。自前のコードはビルドしないので、作り直してコミットする規律も、正本と生成物の一致の検査も生じない。同 ADR は living-spec の検査器に対する決定として有効であり、本 ADR はそれを覆さない。

**却下した代替**:

- **`tools/` に正本を置き、Release の添付物で配る（同 ADR の形）**: 補則とプロファイルを持つプラグインと、検査器の版が別々になる。補則を変えたプラグインを、古い検査器で動かせてしまう。利用者が添付物を入れるまで、write-doc の機械検査が止まる。
- **`tools/` の正本を束ねた1ファイルをプラグインへ同梱する**: 自前のコードの全ての変更に、作り直しとコミットと一致の検査が要る。同 ADR が却下した形と同じである。
- **unified（micromark）を使う**: 上流の単一ファイルが無い。束ねると41のパッケージが入る。
- **シェルの入口（`lint-ja.sh`）を残す**: Node の解決と版の照合の分岐と試験が増える。living-spec の呼び方とも揃わない。
- **awk の実装を併存させる**: 判定が Node の有無で変わる。
- **markdown-it-front-matter を使う**: 閉じの無い `---` があると、文書の終わりまでを front-matter にしてしまう。

## Consequences

- 利用者は、write-doc の機械検査に Node 22 以上を要する。Node が無い環境では、検査器が起動する前にシェルが 127 を返す。
- 解析器の版を上げるときは、上流の単一ファイルを中身を変えずに写し直す。NOTICE の sha256・束ねられた部品・許諾の全文も作り直す。
- 構造を CommonMark と GFM の表の定義で読むので、一部の入力で write-doc の判定が awk の実装から変わる。厳しくなる側と緩くなる側の両方がある。
- 以後に node で動く検査器を同梱する配布物は、この形を前例とする。形とは、素の ESM・ビルドなし・上流の単一ファイルの同梱・`node` の直接の呼び出しである。
