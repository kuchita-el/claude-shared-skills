## 判定の限界

1. **条件2 の時制と退役作業の循環**。現在 `廃止済み` の5本は、2026-07-30 の退役作業の一環として規範本文を living doc へ移送済みである。格下げ基準の条件2 は「判定時点の状態のみを見る」と定めるため、本判定はその移送済みの現状をそのまま (a) と判定した。つまり5本の条件2 成立は、いま判定している退役そのものが作り出した状態に依存する。基準に手を入れない選択の帰結であり、判定結果の解釈時に織り込む必要がある。なお食い違い4本はいずれも条件1 で止まっているため、この循環は4本の結論を左右していない
2. **偶発露出**。「本文の消毒」の表に挙げた2箇所により、ADR-202607261459-01・ADR-202607261503-02・ADR-202606061159-01 の3本は現在の `validity` が判定者の走査面へ露出しうる。前2本の露出は片側（試行1）に偏っており、この2本については2回の一致を独立性の証拠として扱えない。ADR-202606061159-01 は条件2 の担い手の同定経路そのものに開示があるため両試行が到達した公算が高く、この場合の一致は「同じ汚染を受けた2回の一致」であって独立性を示さない。3本のうち ADR-202606061159-01 と ADR-202607261459-01 は食い違い4本に含まれる。ただし試行1 は ADR-202607261459-01 が `廃止済み` であると知ったうえで「存置」と判定しており、露出が判定を現状へ引き寄せた形にはなっていない
3. **層化も無作為抽出もしていない**。対象12本は監査で扱われた既知の集合であり、母集合からの標本ではない。一致率・食い違い率を ADR 全体へ外挿できない
4. **同一モデル・同一プロンプトの2回である**。試行間の差は実行者のみで、モデルもプロンプトも同一である。測っているのは同条件下での再現性であり、判定者の系統的な偏りは検出できない
