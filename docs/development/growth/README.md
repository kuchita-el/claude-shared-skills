# growth の配布元文書

growth プラグインの文書のうち、配布物（`plugins/growth/`）へ同梱せず本リポジトリに留めるものの入口。配布物内／外の別は `docs/distribution-boundary.md` §2 の判断軸が定め、本書はその判断の結果として配布元へ残った文書を列挙する。

本ディレクトリの文書はいずれもストックであり、現在真であり続ける義務を負う。実装・運用が記述と食い違った場合、記述と実装のどちらかを直す。

## 文書一覧

| 文書 | 内容 |
|---|---|
| `design.md` | growth の設計判断の根拠を集約する。実装詳細に近い記述は配布物側の各 spec・各 SKILL.md へ委譲する |
| `career-promotion-spec.md` | ADR 差分・改善還元 Issue への移送規約 |

## 配布物との参照方向

本ディレクトリの文書から配布物（`plugins/growth/`）を相対リンクで指してよい。逆向き——配布物内の文書が本ディレクトリを指すこと——は作らない。`docs/distribution-boundary.md` §3 が定める一方向性であり、配布物のみを導入した利用者から見て解決できない参照を残さないための拘束である。

**この一方向性の正本は `docs/distribution-boundary.md` §3 側にある。** 本節の記述はその言明を再掲したものに留まり、一方向性そのものを定めるものではない。解釈に迷う場合は本書ではなく `docs/distribution-boundary.md` を見ること。

## 提供物の列挙と実体の突き合わせ

growth のスキルの列挙は3か所に在る。配布物の `plugins/growth/README.md` の導入文と「提供物」節、それに `design.md` §4 である。提供物の実体は `plugins/growth/skills/` 直下のディレクトリであり、3つの列挙はその射影にあたる。

実体と各射影を1対ずつ突き合わせ、スキル名の集合が一致することを `scripts/tests/growth-skill-inventory.bats` が検査する。判定の入力（どの節の、どの形の箇条か）は同ファイルが定める。照合するのは名前の集合と、導入文が述べる件数だけであり、各スキルの説明文の一致は見ない。スキルを増減・改名するときは、実体と3つの列挙を同じ変更で揃える。

次の2つの方式は採らない。

- **`design.md` §4 から列挙を落とし、配布物の README を指す（列挙の単一化）**。§4 の各箇条は、各段を実装する担い手の設計上の説明を持つ。`design.md` §3 は担い手の記述を §4 へ委譲しており、箇条を落とすと委譲先の中身が無くなる。
- **列挙どうしを直接比べる**。どの列挙も同じ誤りを持つと、一致して緑になる。`skills/` 直下のディレクトリの増減も拾えない。
