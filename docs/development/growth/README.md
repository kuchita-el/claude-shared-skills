# growth の配布元文書

growth プラグインの文書のうち、配布物（`plugins/growth/`）へ同梱せず本リポジトリに留めるものの入口。配布物内／外の別は `docs/distribution-boundary.md` §2 の判断軸が定め、本書はその判断の結果として配布元へ残った文書を列挙する。

## 文書の2性質

本ディレクトリの文書は、記述が負う義務の点で2種類に分かれる。読み手が「この記述は今も真か」を問うたとき、答えはこの分類から決まる。

- **ストック**: 現在真であり続ける義務を負う。実装・運用が記述と食い違った場合、記述と実装のどちらかを直す。
- **時点固定**: 記述された調査時点の観測であり、以後を追わない。現在の実装や現在の外部仕様と食い違っていても記述の誤りではない。参照する側が、利用の時点で再検証する義務を負う。

## 文書一覧

| 文書 | 性質 | 内容 |
|---|---|---|
| `design.md` | ストック | growth の設計母艦。現在の設計判断の根拠を保持する |
| `adr-candidates.md` | ストック | ADR 化候補の追跡表。粒度判定列は判定当時の結論の記録であり、未昇格の候補は昇格の局面で判定し直す |
| `career-promotion-spec.md` | ストック | ADR 差分・改善還元 Issue への移送規約 |
| `auto-trigger-spec.md` | 時点固定 | 自発トリガー機構の発火仕様と取得可能データの一次調査（#379。調査日 2026-06-28）。実装時に再検証を要する |
| `session-log-format.md` | 時点固定 | セッションログ形式の一次調査（#378。調査日 2026-06-27）。実装時に再検証を要する |

時点固定の2本は冒頭に「調査時点・対象バージョン」と揮発性の注意を持つ。そこに記された調査日と観測バージョンが記述の有効範囲であり、恒久判断（実現可能性・制約・後続実装への前提条件）と版依存スナップショット（payload のフィールド名・レコード構造）の別も各文書が明示する。分類の判定はこの区別に従い、文書単位では時点固定でも、その中の恒久判断は版が動いても効き続ける。

## 配布物との参照方向

本ディレクトリの文書から配布物（`plugins/growth/`）を相対リンクで指してよい。逆向き——配布物内の文書が本ディレクトリを指すこと——は作らない。`docs/distribution-boundary.md` §3 が定める一方向性であり、配布物のみを導入した利用者から見て解決できない参照を残さないための拘束である。
