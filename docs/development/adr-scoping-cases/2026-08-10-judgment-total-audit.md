# 判定記録の合計列監査（2026-08-10）

Issue #715 に伴うスキーマ変更前に、既存の判定記録 TSV について、記録された合計（変更前の7列目）と項目1〜4（3〜6列目）の和を照合した。

対象は次のファイル群である。

- `docs/development/adr-scoping-cases/runs/*-judgments.tsv`
- `scripts/fixtures/adr-scoping-cases/judgments/*.tsv`

監査結果は **不一致 0 行** だった。したがって、既存の項目1〜4の値は変更せず、合計列だけを除去し、今後は検査器が項目1〜4の和から導出する扱いとした。不一致行があった場合に必要となる個別の訂正・注記は発生していない。

監査に用いた照合条件は次のとおりである。

```text
sum = $3 + $4 + $5 + $6
不一致 = ($7 != sum)
```

変更前の `origin/main` 上の全対象ファイルに対する結果: `mismatches=0`。
