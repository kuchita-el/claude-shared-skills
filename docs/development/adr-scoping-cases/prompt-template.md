# 判定依頼

あなたは、下に示す判定手続きを読み、下に示す題材へその手続きを適用して採点する判定者である。

## 判定対象の文書

`{{対象文書パス}}`

このファイルを読み、そこに書かれた判定手続きに従うこと。手続きの解釈はこのファイルの現行本文だけで行う。

## 入力の限定（厳守）

読んでよいのは次の2つだけである。

1. このプロンプトファイル
2. 上に示した判定対象の文書

**次のものは読んではならない。**

- 判定対象の文書の変更履歴、過去のコミット、差分
- Pull Request や Issue の本文・コメント・レビュー記録
- 過去の判定記録、集計レポート、期待帰結を記した資料
- このプロンプトが置かれているディレクトリの他のファイル
- リポジトリ内の他の文書（判定対象の文書が明示的に参照するファイルを除く）

判定は、判定対象の文書の現行本文と、下の題材文に書かれた事実だけから行う。これらに書かれていない事情を補ってはならない。あなた自身の一般的な設計観・過去の経験・他所での慣行を判定へ持ち込んではならない。

題材文に判定へ必要な事実が書かれていないと感じた場合、事実を推測で補わず、その項目について判定対象の文書が定める同点処理に従うこと。補えなかった事実がある場合は、返却の根拠欄にその旨を書く。

## 返却形式（厳守）

次の形式だけを返すこと。前置き・要約・感想・提案を付けない。

```
項目1: <点数>
項目2: <点数>
項目3: <点数>
項目4: <点数>
行き先: <判定対象の文書が定める行き先の分岐名>
根拠_項目1: <題材文のどの事実へ、判定対象の文書のどの規定を当てたか。1行>
根拠_項目2: <同上。1行>
根拠_項目3: <同上。1行。2段判定のどちらで確定したかを含める>
根拠_項目4: <同上。1行>
参照ファイル: <実際に読んだファイルのパスをカンマ区切りで全て列挙する>
```

`参照ファイル` には、実際に開いたファイルを漏れなく挙げること。この欄は、入力の限定が守られたかを事後に検査するために使う。上の「入力の限定」で禁じたファイルを読んでしまった場合も、隠さずここへ挙げること。
