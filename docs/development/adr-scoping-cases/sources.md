## 2. 表の読み方

各エントリは次の10項目を持つ。列が多く Markdown 表では読めなくなるため、通し番号ごとの見出し＋定義リスト形式を採る。

- **入力の記述** — 判定へ与えられた入力事実。一次資料の語をできる限り保存する
- **示された帰結** — その時点で示された点数と経路。項目3 が主だが、判明している他項目も記す
- **初出の巡** / **指摘番号** — 当該入力が一次資料に最初に現れた巡と節
- **確定値** — 最後に示され、以後の巡で覆されていない帰結
- **確定した巡** — 確定値が示された巡
- **最終巡の題材番号との対応** — `題材N` または `対応なし`
- **割れの内容** — 何と何に分かれたか。割れていない場合はその旨
- **出所** — 投稿順の通番と節見出し
- **備考** — 再掲の履歴、未特定の理由、判断を保留した点

通し番号は `S-NN`。S-01〜S-14 が抽出1（題材1〜14 の復元）、S-15 以降が抽出2（巡5〜巡11 で判定が割れた入力、および同区間で通されたが題材番号の付いていない入力）にあたる。

**入力が再現できると判断した根拠**: 各エントリは「入力の記述」に一次資料の語を保存し、「出所」にその記述が現れたコメントの投稿順通番と節見出しを記している。**この2項目が揃っていることをもって、当該入力は再現できると判断した。** 1〜5巡目由来の入力についても同じ基準を適用しており、題材集合へ入れた S-01〜S-08 系の入力はいずれもこの2項目を備える。逆に、一次資料が判定の帰結だけを述べていて入力事実を復元できないものは題材化していない。

## 8. 判断を保留した点

一次資料だけでは決まらず、Task 1・Task 2・Task 3b での判断を要する点を列挙する。本台帳では推測で埋めていない。

1. **S-01（題材1）の期待経路**: 発見型短絡を使う経路（項目1・項目2 は評価を要さない）と使わない経路（1/1/0/0）のどちらを期待値とするか。
2. **S-07（題材7）の保持先**: 「Issue にのみ在る」（巡6レビュー #12 の記述）と「作業者の記憶にのみ在る」（巡3応答 #6 の題材F）のどちらを題材文に採るか。帰結は同じだが入力事実は異なる。
3. **S-16 と題材4 の同一性**: 同一の決定を指すことは一次資料から確定できるが、題材4 の記述には「採用理由を確かめられるかどうか」が含まれておらず、S-16 の割れをそのままでは踏めない。題材4 へ事実を足すのか、別題材として起こすのか。
4. **S-19 と題材13 の関係**: S-19 は題材13 と同一の規範を指すが、題材13 の記述は資産数を数え終えた形（「2資産へ跨る」）で書かれており、条件3 の資産計数の割れを踏めない。題材13 の変種として起こすか、独立の題材とするか。一次資料が題材番号を与えていないため本台帳では `対応なし` に置いた。
5. **S-18 の題材化の形**: 割れを再現する題材（規範の所在を書かない）として入れるのか、所在を書き分けた2題材の対（S-18 と S-22）として入れるのか。
