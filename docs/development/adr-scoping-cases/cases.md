# 固定題材集合（題材文層）

このファイルは、`plugins/adr/skills/manage-adr/references/adr-scoping.md` を被テスト対象とする固定題材集合のうち、**題材文の層**だけを持つ。各題材が導くべき帰結（期待値）は同じディレクトリの `expectations.tsv` へ分離してあり、このファイルには一切書かない。判定を担うサブエージェントへ渡るのは `### 題材文` 見出しの下にある本文ブロックだけであり、題材IDの見出し・その直下のメタ行（出所・資産種別・規範の担い方）・この前書きは渡らない。題材文には、被テスト対象が判定の入力として名指しする事実だけを書き、被テスト対象が結論として述べる述語（採点結果・経路・判定の語）は書かない。事実と結論を混ぜると、被テスト対象を読まずに題材文だけから帰結を再生できてしまい、被テスト対象を改訂したときに帰結が変わるかどうかを検出できなくなるためである。

題材IDは `CASE-NN` で安定させ、各題材の見出し直下の「出所」行で `sources.md` の通し番号へ対応付ける。PR #603 最終巡の題材番号を持つものは、その番号も併記する。最終巡の題材番号を持たない題材（一次資料で番号が付かないまま判定が割れた入力に由来するもの）と、既存の題材から時点や事実を書き分けて派生させた題材については、その旨と派生元を出所行に書く。
