# 返却スキーマ移行記録

## 実行内容

変換は次のコマンドで行った。対象は保存済み返却 JSON のみで、`*-raw-returns.md` は変更していない。

```bash
for dir in docs/development/adr-scoping-cases/runs/*-returns; do
  bash scripts/migrate-return-schema.sh "$dir"
done
```

順変換は対象11フィールドの欠測語だけを `欠測` 辞書へ移し、欠測が無い返却へ `"欠測": {}` を追加する。散文欄は走査・書換えしない。スクリプトは冪等であり、逆変換は次で行う。

```bash
bash scripts/migrate-return-schema.sh --reverse <返却ディレクトリの複製>
```

## 不変条件と照合

各 JSON が保持する対象文書 commit を `--doc-commit` に渡して derive/crosscheck を行い、現行対象文書の版へ依存しないようにした。変換前後の項目1〜4・合計・行き先および走行ごとの照合結果は一致し、照合件数は 42 / 48 / 10 / 2 / 2 / 8、スキップ・不一致・欠落・孤立はいずれも0である。期待帰結層の値に変化はない。

保存済み JSON は機械変換を経た派生であり、判定器が返した当時の形は `*-raw-returns.md` が保持する。D4（案Y）に従い、面⑯sexies は保存済み JSON を複製へ逆変換してから `jq -S` で原文の JSON と比較する。これにより原文を一字も変更せず符号化の無損失性を検査している。

この帰結として、面⑯sexies は移行スクリプト `scripts/migrate-return-schema.sh` の `--reverse` モードへ恒久的に依存する。スクリプトは移行完了後も使い捨て資産ではなく、削除すると常設の返却全文一致ゲートが実行不能になる。
