## 観測したこと

- 地の文に長いコマンドを書くと、検査器はそれを1文として数え、一文長の違反にした。
- 同じコマンドをコードブロックへ移すと、違反は消えた。コードブロックの中は数えなかった。

## 言えること

長いコマンドやパスを文書に書くときは、地の文に埋めず、コードブロックへ置く。文を短く書き直す必要は無い。

## 当てはまらない場合と、確かめていないこと

- インラインのコード（バッククォート1つ）の中を数えるかは、個別には確かめていない。
- 1つのタスクでの観測である。
