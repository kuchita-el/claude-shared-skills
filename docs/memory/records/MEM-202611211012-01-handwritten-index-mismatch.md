## 観測したこと

2026年11月に、記録の形式の検査器を、実際の記憶のリポジトリへ掛けた。そのリポジトリには、人間とは別の AI（Codex）が、利用規則だけを読んで書いた記録が在った。

- その記録に、形式の違反は無かった。
- 検査器が違反として報告したのは、手で書いた索引が、生成した索引と一致しないことだけだった。

## 言えること

- 索引は手で書かず、記録から生成する。
- 索引が記録と一致しないことは、機械で検査する。

## 当てはまらない場合と、確かめていないこと

- 1回の観測である。確信度を medium にしたのは、このためである。
- 観測の時点（2026年11月）は、出典の変更が出された日付から取った。出典の本文は、時点を書いていない。
- 出典は、検査器を足した変更の説明のうち、検証の節である。そこに書かれていないこと（記録の件数、索引のどこが一致しなかったか）は、確かめていない。
