# growth プラグイン

セッション内の学習シグナルを観測・検証し、汎用的な振る舞いルールとして配布する Claude Code プラグイン。生観察の記録から仮説形成・検証・裁定を経て学びを配布物へ届ける学習ループ（`[Capture] → [Distill+Route] → [Promote] → [Distribute]`）を、4つのスキルとして提供する。

## 提供物

- **capture スキル（`skills/capture/`）**: 現セッションの会話履歴から予測誤差検出器（訂正・ツール拒否・反復試行・期待違反）と教示信号検出器（選好・却下理由・目標表明・設計判断）で学習シグナルを検知し、解釈を加えない生観察として個人ローカル store に記録する。判断は後回しにし「何が起きたか」のみを記す。
- **distill スキル（`skills/distill/`）**: 個人ローカル store に溜まった未処理の生観察をバッチで仮説形成し、知識型（摩擦知・判断知）に応じた出力形へ変換してスコープ仮説タグと provenance を付与し、仮説ファイルへ永続化する。検証・起票・配布は行わない。
- **promote スキル（`skills/promote/`）**: distill が永続化した仮説を検証し、検証を通過した仮説のみ `gh` で Issue へ自動起票して既存ワークフロー（refine / DoR / PR レビュー）へ疎結合に渡す。起票前の人間承認ゲートは置かない。
- **intake スキル（`skills/intake/`）**: 複数の仮説 Issue を1つの取り込み Issue へ束ね、人間が昇格先を裁定する集約点を運用する。裁定の承認後、各仮説を取り込み時クローズして inbox から外す。
- **`learnings.md`**: 検証と裁定を経て配布される学びの実体。振る舞いルールを1エントリ1欄で集約したファイル。

設計判断の記録と機構選定の一次調査記録は本配布物に含めない。配布物が持つのは学習ループを回すスキルとその動作契約、および配布される学びの実体である。

## 導入

ローカル marketplace 経由（推奨）、または `claude --plugin-dir /path/to/plugins/growth` で読み込む。恒常有効化する場合は導入先リポジトリの `.claude/settings.json` の `enabledPlugins` に登録する。各スキルは明示的な起動で呼び出し、ハーネスによる自動トリガーは持たない。
