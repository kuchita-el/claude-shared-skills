# 要求の構造化

要求を3層の正本（RDRA の表・要求票・例）へ落とし、名前と参照と層間の追跡が機械検査で通り、規則間の矛盾が突き合わせで潰れた状態で終える。

書式・置き場・検査の規則の正本は `${CLAUDE_PLUGIN_ROOT}/references/format.md`。着手前に読む。雛形は `${CLAUDE_PLUGIN_ROOT}/references/templates/`。

## 引数

要求の出どころ（会話の内容・ファイルのパス・Issue 等）。無ければ会話の直近の要求を使い、それも無ければ何を構造化するかを問う。

## 手順

### 1. 現状を読む

- 根の `.living-spec.json` があれば置き場を読む。無ければ既定（`docs/rdra` 等）
- 表の置き場が既にあれば、表・要求票・例を読み、`node "${CLAUDE_PLUGIN_ROOT}/scripts/living-spec.mjs" check` を実行して出発点の違反を把握する。違反があれば、要求の構造化より先に直すかを利用者に問う
- 置き場が無ければ新規に始める。可視化の書き出し先（既定 `.cache/living-spec/`）を `.gitignore` へ足すかを利用者に問う

### 2. 要求を表へ写す

要求の文から、アクター・外部システム・情報・状態モデル・UC・条件・バリエーションを拾い、表へ足す。既存の要素と同じものは既存の名前を使い、新しい名前を作らない。

- 名前は業務の言葉で、利用者が実際に使う語にする。1つの概念に1つの名前
- 条件の中身（どういうときに満たすか）は条件の表の `条件の説明` だけに書く。要求文・例に書き直さない
- 状態の遷移は `state` 表に1遷移1レコードで書き、遷移 UC を付ける
- 決まっていない要素（試す段階の仮説）は `仮説` キーを付けて登録だけにとどめ、要求票・例は書かない
- 要求の文から決まらない業務の事実（誰が・いつ・何を基準に）は、推測で埋めず問いとして溜める

### 3. 問いを解く

溜めた問いを、業務の言葉で1件ずつ利用者に問う。表の語や記号を前に出さず、「申請を差し戻したら、前の内容は残りますか」の形で問う。情報の形・状態の数が変わる問いを先に問う。答えは表へ反映する。

### 4. 要求票と例を書く

仮説でない UC ごとに、雛形に沿って要求票と例を書く。

- 要求文は EARS の型。UC の条件と、UC が遷移先にする状態を RDRA 欄に挙げる
- 例のルール名は要求文をそのまま写す。例は規則の境界を分けるものに限り、1ルール3件まで
- 既存の票・例を直すときは、要求文とルール名を両方直す

### 5. 機械検査を通す

`node "${CLAUDE_PLUGIN_ROOT}/scripts/living-spec.mjs" check` と `check --doc-missing` を実行し、違反を0件にする。PostToolUse フックが入っていれば、表・票・例の編集のたびに全体検査が走り、違反は編集の直後に返る。違反を消すために検査を外したり、規則を緩める書き方へ逃げたりしない。

### 6. 規則間の矛盾を突き合わせる

機械検査は名前と参照しか見ない。`rule-crosschecker` エージェントへ、根・置き場・この回で足したり変えたりした要素の名前を渡し、独立した文脈で矛盾を探させる。起草の経緯は渡さない。

返った指摘を1件ずつ扱う。

- blocker は直す。どちらの正本を直すかが業務の判断なら、両方の規則を並べて利用者に問う
- warning は直すか、直さない理由を利用者に示す
- 直したら手順5 へ戻る。突き合わせは、直した範囲を焦点にもう一度回す。blocker が0件になるまで

### 7. 描いて見せる

`node "${CLAUDE_PLUGIN_ROOT}/scripts/living-spec.mjs" render` で可視化を描き、書き出した場所と開き方を `view` スキルの手順で示す。

## 出力

終えたときに次を報告する。

- 足した・変えた要素（表ごと）、要求票・例のファイル
- 機械検査の結果（全体検査・書き漏らしの検査それぞれの違反件数）
- 突き合わせの結果（blocker・warning の件数、直したもの、直さなかったものと理由）
- 利用者の判断で決めたこと
- 可視化の書き出し先
- 残った問い（あれば）

## 注意

- 表・票・例は正本で、可視化は派生物。可視化の HTML を手で直さない
- 1つの事実を2層に書かない。食い違いの種になる
- 終わりの判定は、機械検査の違反0件と、突き合わせの blocker 0件の両方。片方だけで終えない
