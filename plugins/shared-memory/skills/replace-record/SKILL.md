# 記録の置き換え

置き換えると決まった記録について、置き換えの3つをそろえ、検査器で確かめる。3つの中身は `format.md` が、そろえる順序は `replacement.md` が定める。置き換えるかどうかは決めない。決めるのは、起動した人間である。

## 文脈固有ルール

- **対象範囲**: 引数で渡された記録の置き換えだけを扱う。扱わないものは、`replacement.md` の「扱わないもの」が定める。
- **成果物**: 置き換えの3つ（新しい記録は、この起動で書く場合）。索引を変更に含める根では、作り直した索引。
- **停止条件**（要るものを報告して終える）: 引数が足りない。変わった理由が、引数にも会話にも無い。置き換えの手順の前提が崩れている（手順2）。検査器が、終了コード 2 で終わった（手順4）。前の3つは、何も書かずに止まる。
- **変更境界**:
  - 旧い記録で変えるのは、`replacement.md` の手順が定める項目だけである。
  - 渡された記録のほかの記録を書き換えない。
  - `index.md` は手で書かない。検査器で作り直す（手順4）。
  - commit・push・PR の作成は行わない。出し方は、その根の規則に従う。

## 引数

| 引数 | 中身 |
|---|---|
| 記憶の根 | 置き換える記録が在る根のパス。必須 |
| 旧い記録 | 識別子。1件以上 |
| 新しい記録 | この起動で書く主張と、その根拠。または、同じブランチの上に在り、まだ既定のブランチに入っていない記録の識別子 |
| `--ref <起点>` | 既定のブランチを指す ref。任意。新しい記録を識別子で渡したときだけ使う |
| 変わった理由 | 何が、なぜ変わったか。理由を述べた者と、確かめたかどうかを含む |

## 手順

コマンドは、下に書いた形のまま、1回に1つずつ実行する。`&&`・`;`・パイプや、`cd`・`echo` でつないだ形は、許可した型に当たらず、拒まれることがある。手順に無いコマンド（`ls`・`printenv` など）は使わず、ファイルの在りかは `Glob` で、中身は `Read` で見る。

1. **読む。** 次の2つを読む。
   - `${CLAUDE_PLUGIN_ROOT}/references/format.md`
   - `${CLAUDE_PLUGIN_ROOT}/references/replacement.md`

   その根の利用規則が在れば、それも読む。在りかは、`format.md` の「記憶の根」が定める順で決める。
2. **前提を確かめる。** 旧い記録を `<根>/records/<識別子>-*.md` で探して読み、`replacement.md` の前提に照らす。当たれば、何も書かずに止める。
   - 新しい記録を識別子で渡されたら、既定のブランチに在るかを、次のコマンドで確かめる。`--ref` を渡されていなければ、`--ref <起点>` を付けずに実行する。結果の扱いは、`replacement.md` の「新しい記録を識別子で受け取るとき」が定める。

     ```bash
     node "${CLAUDE_PLUGIN_ROOT}/scripts/memory.mjs" version <根> <新しい記録の識別子> --ref <起点>
     ```
3. **3つをそろえる。** `replacement.md` の手順の順に書く。識別子の時刻は `date -u +%Y%m%d%H%M`、日付は `date -u +%Y-%m-%d` で得る。
4. **検査する。** 通るまで、手順5 へ進まない。
   - 索引を変更に含める根（その根の規則が、含めないと定めていない根）では、次の2つを順に実行する。2つ目の違反の行（`パス:規則: 説明`）が0行なら、通過とする。

     ```bash
     node "${CLAUDE_PLUGIN_ROOT}/scripts/memory.mjs" index <根> --write
     node "${CLAUDE_PLUGIN_ROOT}/scripts/memory.mjs" check <根>
     ```

   - 索引を変更に含めないと規則が定める根では、`index.md` を書かない。`check <根>` の違反の行から、`index.md:index:` で始まる行を除く。残りが0行なら、通過とする。
   - 終了コード 2 は、標準エラーを示して止まる。
   - 違反が残れば、違反の行の説明に従って直し、検査し直す。
5. **報告する。**

## 出力

- 変えたファイルのパス: 新しい記録、旧い記録、`evolution` の記録、作り直した索引（在れば）。
- 検査の結果: 実行したコマンドと、違反の件数。
- 同じ変更に入れること: `replacement.md` の「コミットに分けるとき」を、変えたファイルの名前で示す。
- 出していないこと: commit していない。出し方は、その根の規則に従う。
