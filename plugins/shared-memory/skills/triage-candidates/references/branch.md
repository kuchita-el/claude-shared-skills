# 選別の変更の用意

案の表を、ブランチの上の変更にする。頼まれたときだけ行う。受け入れるかを決めるのは、人間である。変更を既定のブランチへ入れるのも、人間のマージか直接の編集である。

## 前提

次のどれかに当たれば、何も書かずに止めて、理由を報告する。

- SKILL.md の手順4（別の文脈へ委ねる）が「未実施」だった。案が無い。
- 根が、現在のディレクトリのリポジトリの最上位でない。`git -C <根> rev-parse --show-toplevel` の出力と、`git rev-parse --show-toplevel` の出力を比べる（どちらも正規化されたパスで、相対パスの根や symlink 経由の根でも比べられる）。あわせて、`git -C <根> rev-parse --show-prefix` の出力が空であること（根が最上位であること）を確かめる。比べる2つが等しくない、または `--show-prefix` が空でなければ、何も書かず、Global Memory のリポジトリでスキルを起動し直すよう利用者へ伝える。変更する `git switch -c`・`git mv`・`git rm` は、現在のディレクトリのリポジトリに働き、`cd` と `-C` を使えないためである。
- 起点が、既定のブランチの先端でない。`git rev-parse HEAD` と `git rev-parse refs/remotes/origin/HEAD` の出力が等しくなければ、何も書かず、既定のブランチの先端から起動し直すよう利用者へ伝える。通信はしない。後者が解決できなくても止める。
- `git status --porcelain` に当たるものが在る。作業ツリーが汚れている。

## 手順

1. **ブランチを切る。** ホストか利用者がブランチの名前を定めていれば、その名前で、なければ `date -u +%Y%m%d%H%M` で得た時刻から `triage-<時刻>` として、`git switch -c <名前>` を実行する。起動したときのブランチへは書かない。ただし、ホストがセッションの現在のブランチへしか push できないと定めるときだけは、切り替えず、現在のブランチへ書く。前提の起点の確かめは、この場合も省かない。
2. **案ごとに変える。** 識別子は、新しい記録だけ `date -u +%Y%m%d%H%M` で発番する。同じ分に複数作るときは、連番を増やす。

   | 案 | すること |
   |---|---|
   | 採る | `git mv <根>/candidates/<ファイル> <根>/records/<ファイル>`。言い回しを直すときだけ、移した記録を書き換える |
   | まとめる | 新しい記録を `records/` へ書く。`verification` は `unverified`、`author` は `ai`、`sources` に、まとめた候補と記録の識別子を書く。まとめた候補を `git rm` で除く。下書きの承認は、人間のマージである |
   | 捨てる | `git rm <根>/candidates/<ファイル>` |
   | 補う | 既存の記録へ、主張を変えずに候補の中身を足し、`updated` を改め、`sources` へ候補の識別子を足す。候補を `git rm` で除く |
   | 置き換える | `replacement.md` の手順に従う。新しい記録は、採った候補を移したものか、まとめた記録である。候補は `git mv` で `records/` へ移し、まとめた候補は `git rm` で除く。作業ツリーの `candidates/` から選び、この変更で `records/` へ移す候補は、この変更の新しい記録なので、`version` の確かめは要らない。`evolution` の変わった理由は、案の表の根拠と、人間の指示・直しから書く。人間が直すか確かめたなら `author: joint`、そうでなければ `ai` と `verification: unverified` とする |

3. **検査する。** 索引を変更に含める根では、`index <根> --write` の後に `check <根>` を実行する。含めないと規則が定める根では、`index.md` を書かず、`check <根>` の違反の行から `index.md:index:` で始まる行を除く。残りが0行なら通過とする。違反が残れば、説明に従って直し、検査し直す。終了コード 2 は、標準エラーを示して止まる。
4. **報告する。** ブランチの名前と、変えたファイルを示す。まとめるで、選んだ10件の外の相手の候補を除いたときは、その識別子も示す。commit していないことと、既定のブランチへ入れていないことを書く。

## 守ること

- 変えるのは、案の表に在る候補と、その相手（記録と候補）だけである。
- 案を人間が直していたら、直した案に従う。
- 既定のブランチへ入れない。ブランチを切れなかったときは、止める。
