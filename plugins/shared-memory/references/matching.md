# 照合の手順

主張を、記憶に既に在る記録と照らす手順を定める。同じことを言う記録と、食い違う記録を見つけるために使う。照らす相手には、選別の前の候補と、送り出しの下書きも含める。同じ学びを、運ぶ前や選別の前に重ねて送らないためである。

照合は、主張を書いた文脈とは別の文脈で行うと、書き手の思い込みから独立する。別の文脈で行えないときにどうするかは、呼び出す側のスキルが決める。本書は定めない。

記録と索引の形は、`format.md` が定める。本書は写さない。

## 入力

- 主張の一覧。主張ごとに、番号・主張1文・当てはまる条件・種類を持つ。
- 記憶の根の絶対パス。Project、Global の順に受け取る。無い層は「無い」と受け取る。
- 根ごとの、照らす置き場。省かれたら、その根の全ての置き場を照らす。置き場は、Project が `records/` と `outbox/`、Global が `records/` と `candidates/` である。

主張を挙げた経緯と、書き手の意図は、入力に含めない。

主張の代わりに、記録か下書きのファイルのパスを渡してもよい。その場合は、`title` を主張、`applies-when` を当てはまる条件、`type` を種類として読む。渡された順に番号を振る。そのファイル自身は、照合の相手から外す。

## 読む範囲と順序

- 根ごとに行う。Project を先に、Global を後にする。
- 読むのは、根の `index.md` と、照らす置き場の直下だけである。`outbox/` の下の階層（送り出しの報告）は読まない。
- 根のほかの場所（`tasks/`、`adopted/`、`inbox/`、利用先が置いたディレクトリ）は読まない。
- 全ての記録の本文は読まない。本文を読むのは、手順3 で選んだものだけである。
- 下では、記録・候補・下書きをまとめて「記録」と呼ぶ。

## 手順

1. **索引を読む。** `index.md` を読む。1行が何を持つかは、`format.md` の「索引」が定める。Global の索引の候補は、見出し `## 候補` の表に在る。照らす置き場に `records/` を含まない根では、記録の表を使わない。`candidates/` を含まない根では、候補の表を使わない。
2. **索引に載っていない記録を拾う。** 照らす置き場の直下に在って、索引に行が無いファイルを見つけ、front-matter だけを読む。`outbox/` の下書きは索引に載らないので、全てここで拾う。
   - `superseded-by` を持つものは、対象にしない。置き換えた先が、索引に在る。
   - `moved-to` を持つものは、対象に含める。記憶の外へ移した知識を、記録として足し直さないためである。
   - どちらも持たないものは、索引の行と同じに扱う。作業中のブランチで足したばかりの記録が、これに当たる。
   - ファイルを探す道具が無いときは、この段を省く。見た範囲に「索引に載っていない記録と、`outbox/` の下書きは見ていない」と書く。
3. **1行で選ぶ。** 主張ごとに、主張か当てはまる条件が同じ対象に触れる行を選ぶ。判断の入力は、行の主張と当てはまる条件だけである。迷えば選ぶ。
4. **本文で確かめる。** 選んだ記録の本文を読み、主張と記録の組ごとに、下の「関係」の4値のどれかを決める。

## 関係

| 関係 | 定義 |
|---|---|
| 重なる | 当てはまる条件が重なる範囲で、同じことを主張している。主張を足しても、新しい主張が増えない |
| 食い違う | 当てはまる条件が重なる範囲で、両方は成り立たない |
| 関わる | 同じ対象に触れるが、条件が違うか、主張が別である |
| 関係なし | 選んだが、本文を読むと、触れる対象が違う。または、どの行も選ばれなかった |

- 「重なる」ときは、主張が記録に補うものを添える。補うものは、次の3つである。記録に無い条件での観測。`unverified` の記録を確かめた結果。記録に無い、当てはまらない場合。
- 記録と同じ条件で、同じ結果をもう一度観測したことは、補うものに数えない。再観測のたびに記録を直すと、行動の変わらない変更が積まれるためである。
- 確信が持てない食い違いは「関わる」とし、理由に「未確認」と書く。

## 返す形

主張と記録の組ごとに、次の形で返す。記録の本文と、索引の全文は返さない。

```text
claim=<番号>
relation=<重なる|食い違う|関わる|関係なし>
record=<識別子>  layer=<Project|Global>  path=<根からの相対パス。records/・outbox/・candidates/ のどれかで始まる>
evidence=<記録の本文か front-matter からの、根拠の1文>
adds=<重なるとき、主張が補うもの。無ければ ->
why=<1〜2文>
```

- 主張ごとに、当たった記録の数だけ返す。
- どの行も選ばれなかった主張も、省かない。`relation=関係なし` の1件を返し、`record`・`layer`・`path`・`evidence` は `-` とする。

## 見た範囲

末尾に、1回だけ書く。根ごとに、次を挙げる。

- 照らした置き場
- 読んだ索引の行数（記録の表と候補の表）
- 本文を読んだ記録の識別子
- 索引に載っていない記録の件数と、その扱い
- 無かった根
