# 新規 ADR の束ねの制約（adr-splitting.md）

新規に起こす 1 本の ADR へ何を束ねてよいかを定める。

**「分割」の語は3つの別の判断を指す。** 本ファイルが持つのは3つ目である。

- **いつ分割を駆動するか**（既に束ねられている ADR を分割する適用条件。反転駆動／衛生的分割の2トリガ） → `SKILL.md`「分割（多決定 ADR の部分上書き。5遷移とは別軸の構造操作）」節
- **どう分割を実行するか**（起票・逐語 restate・開示・相互参照の各手順と締めの検査） → `transitions.md`「分割（多決定 ADR の部分上書き）」節
- **そもそも束ねないためにどうするか**（新規に起こす ADR へ何を入れるか） → 本ファイル

## 新規 ADR の束ねの制約

新規に ADR を起こす場合、その1本に何を入れるかは**反転の単位**で決める。

- **独立に反転しうる core を1本の ADR に束ねない。** 束ねた ADR は、一部の決定だけが反転したときに全体を退役させられず、生存する決定を後継へ救出する分割操作を要求する
- **束ねが必要な場合は、束ねた塊が一体で反転する抽象度まで上げる。** 独立に反転する決定は、そもそも同一の core ではない

既に束ねられている ADR をいつ分割するかは別の問いであり、`SKILL.md` 本体の「分割」節が定める適用条件に従う。
