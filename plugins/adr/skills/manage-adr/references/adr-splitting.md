# 新規 ADR の束ねの制約（adr-splitting.md）

新規に起こす 1 本の ADR へ何を束ねてよいかを定める。

**「分割」の語は3つの別の判断を指す。** 本ファイルが持つのは3つ目である。

- **いつ分割を駆動するか**（既に束ねられている ADR を分割する適用条件） → `transitions.md`「適用条件」
- **どう分割を実行するか**（決定の振り分けから締めの検査までの各手順） → `transitions.md`「分割（多決定 ADR の部分上書き）」
- **そもそも束ねないためにどうするか**（新規に起こす ADR へ何を入れるか） → 本ファイル

## 新規 ADR の束ねの制約

新規に ADR を起こす場合、その1本に何を入れるかは**反転の単位**で決める。

- 独立に反転しうる決定を1本の ADR に束ねない。束ねた ADR は、一部の決定だけが反転したときに全体を退役させられず、生存する決定を後継へ逐語転記する分割を要求する
- 束ねが必要な場合は、束ねた塊が一体で反転する抽象度まで上げる。独立に反転する決定は、そもそも1つの決定ではない

既に束ねられている ADR をいつ分割するかは別の問いであり、`transitions.md`「適用条件」に従う。
