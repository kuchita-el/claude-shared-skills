# 記録の参照原則（adr-reference-principle.md）

ADR 本文へ他文書への参照を書く編集と、既存の参照に手を入れる編集の判定を定める。本ファイルが原則と判定テストの実体であり、参照の書き方をここ以外で再定義しない。

本原則は変更分類（core／非core／些末）を問わず効く。分類そのものの判定と操作分岐は `edit-decision.md` が持ち、本ファイルでは扱わない。

## 原則

**記録（ADR）は、可変文書を現在の参照先として指さない。** 指す必要がある場合は、時点を固定した過去形の記述にするか、参照先の実質を自己完結的に述べる。本原則は分類（core／非core／些末）を問わず、ADR 本文へ参照を書く編集・既存の参照に手を入れる編集のすべてに効く（退役 ADR の決定本文は `edit-decision.md` の凍結原則により対象外）。

**判定テスト**: 参照先を空にした状態でその記述を読み直す。**偽になるなら適用対象**であり、時点固定または自己完結化を要する。**真のままなら対象外**であり、記録として既に閉じている。

- **適用対象の例**: 「その規定は現に運用されている」のように、参照先が現にその内容を保持していることを現在形で主張する記述。参照先がその内容を保たなくなれば主張が偽になるため、「当時の」等を補って時点を固定するか、実質を書き下ろす。
- **対象外の例**: 廃止・変更の対象を同定する記述や、当時どこへ委譲したかという予定の記録。参照先が現在何を保持しているかを主張しないため、指し先が空になっても真のまま保たれる。

判定テストは原則の禁止範囲を狭めるものではない。ある記述が「現在の参照先として指す」に当たるかを個別に見分けるための道具である。
