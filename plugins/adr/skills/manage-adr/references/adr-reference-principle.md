# 記録の参照原則（adr-reference-principle.md）

ADR 本文へ他文書への参照を書く編集と、既存の参照に手を入れる編集の判定を定める。あわせて、指すのをやめた後に何を残すかを定める。本ファイルが原則と判定テストの実体であり、参照の書き方をここ以外で再定義しない。

本原則は変更分類（core／非core／些末）を問わず効く。分類そのものの判定と操作分岐は `edit-decision.md` が持ち、本ファイルでは扱わない。

## 原則

**記録（ADR）は、可変文書を現在の参照先として指さない。** 指す必要がある場合は、時点を固定した過去形の記述にするか、参照先の実質を自己完結的に述べる。本原則は分類（core／非core／些末）を問わず、ADR 本文へ参照を書く編集・既存の参照に手を入れる編集のすべてに効く。退役 ADR は、`edit-decision.md` の凍結により対象外である。

**判定テスト**: 参照先を空にした状態でその記述を読み直す。**偽になるなら適用対象**であり、時点固定または自己完結化を要する。**真のままなら対象外**であり、記録として既に閉じている。

- **適用対象の例**: 「その規定は現に運用されている」のように、参照先が現にその内容を保持していることを現在形で主張する記述。参照先がその内容を保たなくなれば主張が偽になるため、「当時の」等を補って時点を固定するか、実質を書き下ろす。
- **対象外の例**: 廃止・変更の対象を同定する記述や、当時どこへ委譲したかという予定の記録。参照先が現在何を保持しているかを主張しないため、指し先が空になっても真のまま保たれる。

判定テストは原則の禁止範囲を狭めるものではない。ある記述が「現在の参照先として指す」に当たるかを個別に見分けるための道具である。

## 所在を送る記述の到達

前節は、何を指してはならないかを定める。本節は、指すのをやめた後に何を残すかを定める。原則の禁止範囲は動かさない。射程は原則と同じであり、退役 ADR は対象外である。

前掲の判定テストは記述の真偽だけを見る。そのため、パスを落として真のまま保った記述が、規範の実体の所在を示さずに終わっても検出しない。本節はその欠けを扱う。

**対象**: ADR の記述のうち、決めた事項の実質（定義・規範の条文・値）が自身の外に在ると述べる記述を、所在を送る記述と呼ぶ。

- 「〜を正とする」「〜に置く」「本 ADR では再掲しない」のように、実質の保持先を指定する記述が当たる
- 保持先は ADR の外の文書でも、同じ ADR の別の記述でもよい。パスの有無は問わない
- 書く編集と、既存の記述に手を入れる編集（パスを落とす編集を含む）で判定する。手を入れない既存の記述へ遡って課さない

**到達テスト**: 所在を送る記述から始め、送り先が同じ ADR の別の記述ならそこへ進む。ADR の外へは進まない。始めの記述を含め、通った記述のいずれかが次のどちらかを満たせば、到達する。

1. 実質の所在を、時点を固定した過去形で述べている（例:「起票時点では `<パス>` の `<節>` が保持していた」）
2. 送った実質を書き下ろしている。ただし、本 ADR では再掲しないと自ら述べた事項は、この条件では到達しない

どちらも満たさずに、送り先が ADR の外で終わるか、既に通った記述へ戻るなら、到達経路は閉じている。閉じた経路は、最後に通った記述へ1か2を補って開く。再掲を避けたい事項には1を補う。判定に迷う場合は、閉じているものとして扱う。1も2も原則に反しないため、誤って補っても記録は偽にならない。

- **閉じている例**: 決定1 が「正式な定義表は決定5 を正とし、本 ADR では再掲しない」と送る。決定5 は「正式定義は規約文書の表に置く」で終わる。決定5 で ADR の外へ出るが、1も満たさず、決定1 の再掲しない旨により2でも到達しない
- **開く補い方**: 決定5 に「起票時点では `<パス>` の表が保持していた」を補う

**既知の帰結**: 到達するのは起票時点の所在であり、現在の所在ではない。そこから現在の実体を探すのは読者の側である。ADR に現在の実体への経路を保たせることは求めない。求めれば、可変文書を現在の参照先として指すことになり、原則に反する。

**判定を置く工程**: 所在を送る記述かどうかは文意で決まるため、機械検査では判定しない。ADR 本文へ参照を書く編集・直す編集の時点で、前掲の判定テストと併せて判定する。

**この規定を置く理由**: 実質が別に在ると述べながら所在を示さない記録は、決定が何を前提にしたかを読者に特定させない。時点固定の所在は1行で足り、原則にも反しない。採らなかった案と理由は次のとおりである。

- **到達できなくてよいとする案**: ADR は決定と根拠の記録であり、実体は資産が持つという論拠に立つ。この論拠は現在の実体への経路を求めない理由にはなる。一方で、起票時点の所在まで落としてよい理由にはならないため、採らない
- **参照先を種類で述べる案**（「定義表を載せる規約文書」）: 一つの文書に絞れるかが読者のリポジトリの知識で変わり、判定者によって結論が割れるため採らない
- **ADR の外の索引へ委ねる案**: 索引自体が可変文書であり、それを現在の参照先として指すことになる。索引を持たないリポジトリもあるため採らない
- **パスを落とした記述のすべてへ広げる案**: 廃止対象の同定のように、実質が別に在ると述べない記述は、記録として既に閉じている。所在を補っても得るものがないため採らない
