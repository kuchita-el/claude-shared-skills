# ADR-20260621-01: 旧規約ファイル名で識別子が重複した1本目

## Status

承認済み

## Context

fixture 用（invalid/28）。front-matter は持つがファイル名が旧規約（時刻部・連番部が新形式でない）のまま、かつ同一識別子の ADR が2本ある状況を再現する。識別子部の抽出を形式適合前提にすると、この重複を取り逃す。実際に旧規約下の重複は1か月以上検出されなかった。

## Decision

fixture 用のため実質的な決定内容は無い。

## Consequences

形式違反2件に加えて識別子重複違反が報告され exit 1 になる。
