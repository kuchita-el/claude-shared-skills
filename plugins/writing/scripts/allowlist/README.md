# 許可リスト

第1条（語の接地）の義務を免除する語形の登録簿。機械検査 `lint-ja.sh` と独立レビュー `doc-reviewer` の双方が同じ内容を読む。片方だけが読むと、同じ条文に対する判定が2つに割れる。

## 書式

- 検査器が読むのはこのディレクトリ直下の `*.txt` である。本ファイルは読まれない。
- 1行に1語を書く。空行と `#` で始まる行は読み飛ばす。行末の空白は無視する。
- 英語トークンの照合は大文字と小文字を区別しない。
- 語ごとの意味定義を書かない。ここは語形のリストであり、用語集ではない。定義を必要とする語は登録せず、本文の側で接地する。

## 登録の基準

読み手がその語を知っている見込みで判断する。**使用頻度を根拠にしない**。

頻度が測るのは書き手の癖であって読み手の理解ではない。読み手が分からないと訴えた語ほど書き手は繰り返し使うため、頻度を基準にすると規約が最も止めたい語から先に免除される。実測でも、読み手が意味を問い返した語は出現ファイル数が多い側にあった。

登録は人手で行う。既存の文書から頻度順に語を抜き出して一括登録する作り方を採らない。

## ファイル

| ファイル | 対象 |
|---|---|
| `english.txt` | 英語トークン |
| `katakana.txt` | カタカナ語 |

漢字の造語はどちらにも登録しない。機械検査が漢字を対象としないためである。漢字の造語の判定は `doc-reviewer` が担う。

## 差し替え

読み手が変われば適切な内容も変わる。プロジェクト側で内容を差し替える場合は、`lint-ja.sh` へ `--allowlist` で別のディレクトリを渡す。
