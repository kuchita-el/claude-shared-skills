# ADR-202612061027-02: H1 の識別子部がファイル名と食い違う

## Status

承認済み

## Context

fixture 用（invalid/27）。ファイル名の識別子部は `ADR-202612061027-01` だが、H1 見出しの識別子部は `ADR-202612061027-02` である。`gen-adr-index.sh` は H1 の `: ` 以降のみをタイトルとして抽出するため、この不整合は生成物に現れない。レイヤ5 が H1 整合違反として検出することを確認する。

## Decision

fixture 用のため実質的な決定内容は無い。

## Consequences

レイヤ5 が H1 整合違反を報告し exit 1 になる。
