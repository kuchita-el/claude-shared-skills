# ADR-202701021013-01: コードフェンス内の Status 見出しと別の語の見出し

## Context

fixture 用。旧形式の見出しの例をコードフェンス内に示しても、節とはみなさない。

```markdown

承認済み
```

## Decision

fixture のため実質的な決定内容は無い。

## Status quo

`## Status quo` は別の語の見出しであり、状態節ではない。
