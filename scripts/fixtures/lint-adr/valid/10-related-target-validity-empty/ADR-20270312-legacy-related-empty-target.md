# ADR-20270312: Related される旧形式の参照先

## Status

Accepted

## Context

fixture 用（valid/10）。有効な source から `Related:` される、front-matter を持たない旧 `## Status` 形式の ADR。`validity` を持たないため、参照先退役違反にならないことを確認する。

## Decision

fixture 用のため実質的な決定内容は無い。

## Consequences

index には現れない（front-matter を持たないため）。実在するため dangling ではない。
