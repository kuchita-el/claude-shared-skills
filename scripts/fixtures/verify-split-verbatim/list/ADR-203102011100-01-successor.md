# ADR-203102011100-01: 原 ADR の決定1・3 を引き継ぐ後継

## Context

原 ADR の決定1・3 を逐語で引き継ぐ。決定2 は後継を立てず原 ADR に残した。

## Decision

1. **一つ目**: 一つ目の決定の本文。
   - 字下げした箇条は項目の続きとして含む

   空行を挟んで字下げした段落も項目の続きとして含む。
2. **三つ目**: 三つ目の決定の本文。

**却下した代替**:

- 後継の文脈で書いた非決定文は照合しない。
