# 検査の入力単位についての判断依頼

## 判断をお願いしたいこと

日本語文書の共通規約に沿っているかを機械的に検査する仕組みについて、既定の入力単位を差分とファイル全体のどちらにするかを決めたい。

**前提**: この検査は変更を確定する前に走らせ、違反が残っている間は確定を止める。報告するだけの仕組みではない。共通規約は、適用する範囲を「新しく起草する文書と、既存文書のうち編集で実際に触れた箇所」と定めており、既存文書の一括是正は対象外と宣言している。2026-08-08 時点で `docs/` と `plugins/` 配下の `.md` を対象に数えたところ、既存文書には規約違反が573件残っていた。

**判断軸**: 適用範囲の宣言と検査の挙動が一致すること、および導入した直後に検査が違反で埋まらないこと。

**選択肢と帰結**:

- 差分を既定にする。検査するのは編集で触れた箇所に限られ、適用範囲の宣言と一致する。既存の573件は、その箇所を編集したときに初めて赤くなる。ファイル全体を見たい場合は明示的な指定が要る
- ファイル全体を既定にする。既存文書を1行直しただけで、そのファイルに残る既存の違反がすべて赤くなる。赤いままでは変更を確定できないため、宣言では求めないはずの是正を事実上要求することになり、一括是正を対象外とした宣言と食い違う

**推奨**: 差分を既定にする。適用範囲の宣言と検査の挙動が一致し、導入した直後から検査を通せるためである。

この文書で問うのはこの1件に限る。
