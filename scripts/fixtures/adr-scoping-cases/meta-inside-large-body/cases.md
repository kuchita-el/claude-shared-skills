# 検査器のテスト用題材集合（正常系）

このディレクトリはテストランナー専用の fixture であり、本番の題材集合とは無関係である。
CASE-A1 の題材文ブロックの内側にメタ行を置き、その後ろに本文を積んでパイプ長を超えさせてある。
メタ行内側の検査をパイプで書くと、書き手が SIGPIPE を受けて検査が無言で素通りする。
題材文の内容は検査器の振る舞いを確かめるための当て馬であり、判定の妥当性を意図していない。
