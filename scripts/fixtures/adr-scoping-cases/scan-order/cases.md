# 検査器のテスト用題材集合（走査順の固定）

このディレクトリはテストランナー専用の fixture であり、本番の題材集合とは無関係である。
違反を持つ題材を複数並べ、診断の並び順が記載・記録の出現順に固定されていることを見る。
題材IDは、awk の連想配列を素朴に `for (k in arr)` で走査すると gawk・mawk のいずれでも
出現順と異なる並びになる組み合わせを選んである（走査順を固定し損ねた実装が露出する）。
雛形は置いていない（validate と report でのみ使う fixture であるため）。

- 出所: fixture（走査順の固定）
- 資産種別: 実装本体
- 規範の担い方: 体現・強制

### 題材文

ある規則を検査するスクリプト1本がその規則を体現しており、違反を検出してコミットを止める（CASE-A1）。
