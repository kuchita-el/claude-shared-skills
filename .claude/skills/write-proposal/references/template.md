# 提案書の骨格（雛形）

見出しと、各節の冒頭 1 文の型。角括弧は埋める箇所。「必須」の節は省略しない。付録の見出しは例であり、素材に合わせて増減する。付録の記号は本文からの参照に使うため、付録の順を変えたら参照も付け替える。

```markdown
# [題名] 提案書

[日付] · [著者]（素材に無ければ省略）

## 1. 結論   ← 必須

[提案を 3 文以内。何を提案し、何を採り、何を条件付きにし、何を退けるか]

- 採用する: [部品]
- 条件付きで採用する: [部品]（条件は 5 節）
- 退ける: [案]（理由は 5 節）

## 2. 求める判断   ← 必須

| 論点 | 選択肢 | 推奨 | 期限 |
|---|---|---|---|
| 本提案の採否 | 採る ／ 条件付きで採る ／ 採らない | [推奨と理由を 1 文] | [素材にあれば] |
| [未決の論点] | [選択肢] | [推奨と理由を 1 文。推奨が無ければ「無し」] | [素材にあれば] |

## 3. 前提   ← 必須

### 3.1 適用範囲と背景

- [人数・対象・言語・規模・現状の制約]

### 3.2 目標と非目標

- 目標: [提案が達成すべきこと]
- 非目標: [目標にしてもよかったが、明示的に目標にしないこと]

### 3.3 判断軸

- [案を比べる観点。5 節の比較表の列になる]

### 3.4 調査から置いた前提

| 前提 | 根拠の要点 | 根拠の強さ | 詳細 |
|---|---|---|---|
| [提案が依拠する事実] | [数値 1〜2 個と出典名] | [例: 対照研究 ／ 大規模実測 ／ 自己申告] | 付録[X] |

## 4. 提案の中身   ← 必須

### 4.1 [原理]
### 4.2 [構成]
### 4.3 [運用の決め事]
### 4.4 [費用対効果]

<!-- 選択肢から 1 つを選ぶ提案では 4.1 採用後の形 → 4.2 運用の決め事 → 4.3 費用対効果 の 3 節にする -->


## 5. 却下した代替案と条件付きの案   ← 必須

| 案 | [判断軸1] | [判断軸2] | … |
|---|---|---|---|
| [提案] | | | |
| [代替案] | | | |

| 案 | 扱い | 採れば得られたもの | 採らない理由または条件 | 詳細 |
|---|---|---|---|---|
| [案] | 却下 ／ 条件付き ／ 考え方のみ採用 | [その案の長所] | [判断軸に結びつけた理由。数値があれば 1〜2 個] | 付録[X] ／ [節] |

## 6. 落とし穴と対処   ← 任意

| 落とし穴 | 何が起きるか | 証拠 | 対処 |
|---|---|---|---|

## 7. 調査の方法と限界（概要）   ← 必須

- 調べた範囲: [1〜2 文]
- 分け方: [1 文]
- 進め方: [1 文]
- 全体に及ぶ限界: [1〜2 文]。詳細は付録[X]

## 付録A. [確認した事実]
## 付録B. [手法の網羅的な比較]
## 付録C. [実測の一覧]
## 付録D. 証拠の限界
## 付録E. 用語集
## 付録F. 出典
```
