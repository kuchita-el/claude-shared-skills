# プランレビュー基準（claude-shared-skills固有）

デフォルト基準に加えて、スキル設計指針に基づく追加観点でレビューする。番号はデフォルト基準の観点 1〜12 に続けて振る。

## スキル設計指針に基づく追加観点

スキルの新規作成・修正を含むプランでは、以下も確認する。

| # | 観点 | チェック項目 |
|---|---|---|
| 13 | SKILL.md の分量 | CLAUDE.md「スキル設計の token 規律」の上限に収まる設計か。超過する場合、参照ファイルへの分離が計画されているか |
| 14 | allowed-tools最小化 | `allowed-tools` がスキルの機能に必要最小限か。不要なツール権限が含まれていないか |
| 15 | description品質 | descriptionに「何をするか」と「いつ使うか」の両方が含まれているか。三人称で記述されているか |
| 16 | 参照の深さ | 参照ファイルの深さが1段階以内か（SKILL.md → 参照ファイル。参照ファイル → 別の参照ファイルはNG） |
