# 要求票: 経費申請を取り下げる

## 理由

従業員が提出を誤ったとき、提出先が処理を始める前なら出し直せるようにする。

## 仕様

1. 従業員が経費申請を取り下げるとき、システムは経費申請を作成中へ戻し、前回提出した内容を残さない
   - RDRA: アクター「従業員」、状態「経費申請の状態/作成中」
   - 理由: なし
2. 取り下げられる条件を満たさないならば、システムは取り下げを受け付けない
   - RDRA: 条件「取り下げられる条件」
   - 理由: なし
3. システムは取り下げられた経費申請を承認済みとして扱う
   - RDRA: 状態「経費申請の状態/承認済み」
   - 理由: なし
